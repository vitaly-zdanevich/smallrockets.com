Small Rockets Mah Jongg
Bored of solitaire? Small Rockets Mah-Jongg is a game of skill and luck for one player. Match tiles and remove them from the board, but watch out - pick up the wrong tile and all will be lost!


Small Rockets Poker
The Small Rockets version of this classic card game is here at last. Choose from a range of game types (5 card draw, 7 card stud, Texas Hold 'Em and Omaha), and play the computer or challenge up to 3 other players via the Internet, using the chat function to bluff your way to victory! Beta version


Small Rockets Backgammon
The classic traditional board game brought to life in this new version from Small Rockets. Play against the computer or against other people via the Internet, with multiple skill levels, 4 different board styles and support for advanced features including the doubling cube.


For our linux games to install and run correctly, please ensure you have libSDL 1.2 and GTK+ installed correctly.

For more information and installation files for these libraries, please visit www.libsdl.org and www.gtk.org respectively.
