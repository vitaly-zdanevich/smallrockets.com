Quick questions and answers on cookies

What is a cookie?

A cookie is a piece of information placed and held on your machine. Its source is the web server you are connected to.

What is Small Rockets policy on cookies?

Small Rockets only uses cookies where it absolutely needs to. The area where this becomes important is tracking a 'session' on a machine. All this means that we need to use a cookie when we need to store information between pages. Currently this is required for the ecommerce system. In particular for

  • Knowing what the shopping baskests contents is
  • Identifying what the user can download

How do I enable cookies on my machine?

It depends on which browser you use. On Microsoft Internet Explorer 4.0

  • Go to the 'View' menu
  • Select 'Internet Options...'
  • Click on the 'Advanced tab'
  • Scroll down to the 'Security' section
  • Inside you'll find a section on cookies
  • Select 'Prompt before accepting cookies' - to be asked when a cookie is written to your machine
  • Select 'Always accept cookies' if you don't want to be asked
  • Click on 'Ok' when you are done
On Netscape Communictaor 4.06
  • Go to the 'Edit' menu
  • Select 'Preferences'
  • Highlight 'Advanced' by clicking on it
  • Select the 'Accept all cookies' button
