How do Small Rockets games work?

All Small Rockets games are distributed electronically. That means you can obtain them by downloading them via the Internet, and you do not have to buy a physical copy of the game.

The games are completely free to download. When you download and install a game, it will run as a demo (or trial) version - a small selection of levels and features will be available to sample, so you can judge whether you'll find the full registered version interesting and exciting.

To play the full version, all you need to do is purchase a license code. All the files the game requires are contained in the demo version you've already downloaded, so you don't need to download anything else. Once you have the license code, the full version can be unlocked instantly!

How do I buy a license code?

  1. Download and install the demo.
    Select the game from the home page, click on 'Download' and select a location. Once the installation file has downloaded, double-click on it to install the demo.

  2. Select "Buy the game"
    You can either do this from the website or from within the game.

    From the website
    Click on "Shop", and select the game(s) you wish to buy. Select "Buy it now". You will be taken to the shopping basket screen. Here you can add more games to your order if you wish, cancel your order or proceed to the checkout. To continue with your order, select "Pay at the Checkout".

    From the game
    Click on the "Buy Game" option from the main menu or the full version advertisement screen, or from the "Get The Full Version" option on the game's Window Start menu entry. This will take you to a browser window; you should ensure you are connected to the Internet, and click on the link to buy the game via the net.

  3. Log on to your account
    You will now be prompted to log on to an existing account if you have one, or to open a new account if you have not bought a game from us before.

    To open an account, you will need to supply your name and email address. Important - you must enter a valid email address, as all license keys you buy will be sent to this address.

    You will also be asked to supply a password, plus a hint that will be used to remind you if you forget the password.

  4. Enter your credit card details
    Enter your credit card details as prompted. Make sure you enter your credit card name exactly as it appears on your card.

  5. Enter your address and telephone number
    Your address should be the billing address for your credit card.

  6. Confirm your order
    Please check your details, and if you are happy with them, select "Confirm Order". If you wish to change anything at this stage, simply click the Back button on your browser. This is your last opportunity to change your order before the payment transaction is completed.

    When you have confirmed your order, after a short pause you should receive a message saying that the transaction has been successfully completed. At the same time you will automatically be emailed with the license code for your game.

    Please note - all account transactions and purchases take place over a secure link to our servers. If you'd like to find out more about our security, click here.

How do I use the license code once I've bought it?

There are two ways to use your license code to unlock the full registered version of the game - automatic and manual.

Automatic registration
When you receive the email with your license code, you'll find there's an attachment called "license.fgk" (a file which contains license code details). Make sure you've installed the demo version first, then save this file to a folder in Windows. Double-click on the saved file, and the game will automatically be registered and unlocked.

Manual registration
You can also enter the license code manually. The code is written in the confirmation email as 13 digit sequence of numbers and letters, in the form X-XXXX-XXXX-XXXX. To use this code, do the following:

  1. Ensure that the demo is installed and working correctly.
  2. Quit the demo, and look for the game's menu under Windows Start (normally found under Programs/Small Rockets).
  3. Select 'Set The Game License'.
  4. Enter your name exactly as it is on your credit card, and your 13 digit license code (including dashes) in the boxes provided, and click 'OK'.
  5. You should receive a message saying that the game has been successfully unlocked. You can now play the full version of the game.

Not at the moment. Small Rockets is an Internet-only company and we simply do not have the facility to send out CDs. It's one reason why we can sell our games so cheaply! However, we may produce a CD with all the demos on it at some point in the future.

If you're worried about losing the game once you've bought it, rest assured that you will always be able to download any of the game demos from site, and you can always look up any license codes bought from Small Rockets by logging into your personal account. Please send us an international money order (or cheque if you're in the UK), together with an order form which you can obtain from the Shop section of our site. The cheque or money order must be in US dollars or pounds sterling.

We'll then send you the license code(s) by return. We advise against sending money in the post, as it can easily get lost in transit!

I'm having difficulty downloading your games.

Make sure you're downloading from a server closest to your geographical location. Our servers get very busy, so if your connection is slow try downloading at an off-peak time.

If the game refuses to install, it may be that your download was incomplete; in this case, you may need to download a new working version from our site.

Note: some AOL subscribers have had occasional difficulties with incomplete downloads. If you connect via AOL and you're experiencing problems, we suggest you contact our Technical Support team directly for more help.

My hard drive was wiped and I lost the game. How do I restore it?

Here's what you need to do:

  1. Download a new copy of the game demo and install it.
  2. In Windows, log on to your Small Rockets account using your name, email and password. If you bought your license code from Fiendish Games, you'll need to visit the Fiendish Games site and transfer your details to Small Rockets before performing the step above.
  3. You should be able to see all the codes you have bought so far. Make a note of your user name as it appears there and the appropriate license code.
  4. From the Windows Start Menu, select the appropriate game menu (normally found in Programs/Small Rockets).
  5. Select 'Set The Game License'.
  6. Enter your user name and licence code exactly as you wrote them down earlier.
  7. The full version should now be available again.

The game doesn't work when I install it.

First of all, you should check that your computer meets the minimum required specification for the game you're trying to play. This information can be found on the technical support pages of individual game manuals, or in the game-specific pages on this site. The minimum spec varies from game to game, but the following are usually essential:

  • a Pentium processor (or equivalent)
  • Windows 95 or higher
  • a 3D accelerator card
  • a sound card
The technical support pages in the manual and on this site also contain a wealth of advice about trouble-shooting, so you should read these to see if there is a specific solution to your problem.

Finally, if all else fails, you can contact our Technical Support team by emailing support@smallrockets.com. Please note that this service is only available to REGISTERED users of the games.

When you email Technical Support, you must attach a 'dxdiag' report (this details the precise technical configuration of your PC, and is invaluable in helping us to diagnose and fix problems quickly). Here's how:

  1. From the Windows Task bar click on START
  2. Select RUN from the drop down list that now appears
  3. Type DXDIAG in the command line window that opens when you click on RUN.
  4. The application that now runs allows you to view the current hardware settings of you machine and save a report out to your hard drive by clicking on the button entitled SAVE ALL INFORMATION.
  5. Once you have the report, attach it to an e-mail to support@smallrockets.com
