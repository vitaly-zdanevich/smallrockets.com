# smallrockets.com (Wayback Machine Archive)

Static historical archive of **smallrockets.com** (including preserved subdomains under `_hosts/` such as `corporate.smallrockets.com`, `downloads.smallrockets.com`, `highscores.smallrockets.com`, `pc.smallrockets.com`, and `webgames.smallrockets.com`), reconstructed from the latest usable Internet Archive Wayback Machine captures for cultural and historical preservation.

- **Browse archived site (GitHub Pages):** https://vitaly-zdanevich.github.io/smallrockets.com/
- **Created with:** [webarchive_downloader_rust](https://github.com/vitaly-zdanevich/webarchive_downloader_rust) (commit `ce24e1f`)

## Notes

- All internal links, stylesheets, scripts, and assets are rewritten to relative paths for offline browsing and static hosting.
- `.nojekyll` is included so GitHub Pages serves raw static files directly, including subdomain directories under `_hosts/`.
