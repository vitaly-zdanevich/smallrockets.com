Hi,

Which version of Windows XP are you running? I've had no problems running most of SR's older games under Windows XP Pro. (NFK is an exception though. I suspect this one may need a new graphics engine before it'll work as it's getting on a bit.)

Even Red Ace Squadron seems to work, although the front-end suffers from some minor glitches if you run at a high resolution. I do know that a couple of their games will never be upgraded simply because they bought them in from an external developer based in Eastern Europe. They don't have the source code for these games, so they can't do anything to fix them. (The Kayaking game is one of these.)

As I understand it, most of the incompatibility problems seem to be with XP Home, rather than XP Pro.

As these versions of Windows are more secure, you need to be aware of the way they handle user security. Make sure you're installing as a user with "Administrator" or "Power User" status, not just "Standard User". This may help. I would advise making sure you register the game as an Administrator or Power User too, although you should be able to play the game as a standard user once this is done.

If you are still having problems, please try and detail all the symptoms:

* Is the game not installing?
* Is it running fine as a demo, but failing when you register it?
* Is it running with visual or audio glitches?
* Does it crash only at certain points in the game?
* What graphics card are you using?
* What audio card do you have?
* What driver versions are installed?
* Do you have any Service Packs installed?
* What version of Windows are you running?

Add anything else you can think of that might be relevant. If you can run "DxDiag.exe" (use the "Run..." command in the Start Menu), a full report from this could be most useful.

The more information you can give SR, the easier it is to nail down where the problem is occurring and work out how best to fix it.

Regards,
