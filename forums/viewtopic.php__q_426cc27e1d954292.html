Hi,

well the networking system is going to change with RAS2. The big difference is that RAS1 used two techniques that we'ren't so great when it comes to routers.

1) It was peer-to-peer
2) It used a combination of DirectPlay + TCP/IP

The peer to peer system meant fast and responsive action on clients, but has meant lots of other complications including security, and a router having to handle lots of different connection.

Using DirectPlay has been a nightmare. To connect the machine has to make multiple ports open, and allow a 'back connection' to your machine.


The new networking technology will be strictly client-server and will use UDP/TCP IP through a single port.

This will make easier connections. Better security, and should make the game work easily behind almost any router. Only complication will be if you have a server - you'll still have to set up a port rerouting like you do now.

Hope this helps,

Jonathan
