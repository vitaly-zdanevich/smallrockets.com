LL....

First off.... everything your SERVER is DOING and SAYING is CORRECT and NORMAL.... every PRO SERVER (and others) are basically the same. The 6114 refers to the PORT that the server is utilizing. The update numbers are the sequencing of the program.... which as you have already noted... go on forever. The Pro Server 1.09 is the final latest version.... the Network 1.08 does not say 1.09 because you only change the version number when something is actually changed. The server configuation only went through 8 changes.... the program itself... 9. So I hope that eases your mind.

I have seen lobby chat in GameSpy where a few folks have tried to help you. Every conceivable problem fix, to my knowledge, is addressed in the HELP documents.

http://www.smallrockets.com/forums/viewtopic.php?t=10203

The only exception would be something to do with your own computer. The countdown thing, to me, indicates a router or firewall problem since you have the Small Rockets version and not the Real Arcade (which does not work presently in RAS Multi-Player).

I know you are frustrated and believe me, I and others want to help you any way we can. PLEASE go back over ALL the things in the HELP documents. Go through one by one. If you are already playing Multi-Player in a differnt game... that would eliminate the router / firewall possibility.

Hi there,start the Red Ace Pro Server from the Start Menu/all programs/Smallrockets folder of your PC.
Then minimize it to your system tray.Next press the "play Red Ace Squadron Pro" button on the start menu/smallrockets list.
After the game loads press Multiplayer button then "Change server IP" button.
Add your IP number in the space provided and then press ENTER.
Press the Multiplayer button again and select "Internet connect button"
This will allow you to join your own currently running server.
At this point if it just counts down and does not take you to the online server then a firewall is blocking access.This may not be visable to you as it may be behind the game screen you are looking at.
Allow the file"AceNet Client release"(C:/programfiles/Smallrockets/Red Ace Squadron folder) as a trusted program in your filewall.
