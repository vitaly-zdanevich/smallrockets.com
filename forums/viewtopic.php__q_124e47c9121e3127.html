Hmm. Looks like you may need to play with the relevant .INI file. Our games pick either the JOYSTICKKEYS.INI, KEYBOARD.INI or MOUSEKEYS.INI file according to your chosen control method. You'll find these in either:

"C:\Program Files\Small Rockets\[NAME OF GAME]\" (for Windows XP, Vista or 7, 32-bit editions)

or:

"C:\Program Files (x86)\Small Rockets\[NAME OF GAME]\" (for Windows Vista or Windows 7, 64-bit editions).

In each of these, you should see an entry like this:

[Player1Throttle]
sensitivity = 1
upkey0 = dot
upkey1 = rightshift
upkey2 = leftshift
downkey0 = comma
downkey1 = leftctrl
downkey2 = rightctrl
type = keyboard

(If you see any blank lines, try removing them. It shouldn't make any difference, but then again, it should already be working!)

Note the entries I've bolded above: these refer to the right [shift] and right [ctrl] keys respectively and are, by default, already set up. So they should be working. If they're not, something's not right and you should check if your keyboard's driver is interfering with the process. It may be that you need to update the keyboard's driver software, in which case Logitech's website should have something available.

PC keyboards have a long and surprisingly complex history. The upshot of this is that PCs have to support multiple scan code systems. (By contrast, Apple have used much the same keyboard layout since 1984.)

It's possible your own keyboard is using some naughty tricks to achieve a particular feature, or have a buggy driver. Check with Logitech's website to see if a newer driver is available.
