Er, RAS2 _is_ in development. However, Jon has asked me to apologise on his behalf for his overly optimistic release plans.

Jon was originally going to use off-the-shelf middleware to speed up development, but there aren't many options for the downloadable games market.

The major middleware vendors proved too expensive. Other, "indie" middleware solutions simply weren't powerful enough or flexible enough.

In the end, he decided to bite the bullet and build his own middleware. (Jon developed the engine on which Renderware was based, so he's certainly got the experience.) Middleware isn't trivial however: for the new tools to be worthwhile, he needs something that can handle networking, internet play, 3D graphics (with all -- or at least most -- of the mod cons, such as programmable shaders), a set of tools to back it all up, and audio support too.

The plan now is to make this all sufficiently powerful that he can use it confidently for the next 7-10 years' worth of games. This all takes time.

RAS 2 _is_ coming. Absolutely, 100% definitely. The "Red Ace" games are our best-selling titles, so Jon would have to be mad not to.

It's just taking rather longer than expected. For which we can only apologise.

roossell95 wrote:I think new maps, planes, AND missions would be great. Maybe each quarter there could be a pack to download with x amount of each type of addon.


This is Jon's general intention. I'm not sure how often he can release new updates and missions, etc., so I can't comment on that. It depends on how successful the game turns out to be.

By the way, why do all the planes in the screenshots have the same texture? And also, all of them are Fokker DVIIs, but the textures have red white and blue on the tail. Are these only temporary test textures?


Sort-of. There's certainly some placeholder art, but our "Red Ace" games aren't meant as hardcore simulations with 100% accuracy: they're meant to be fun games, so allowing some "What-if?" scenarios is also fair game. For example: It's possible that a multiplayer game option would allow players to pick any plane available in the game, regardless of what side they're on. This may be historically inaccurate, but it does allow players to fly each other using identical planes, ensuring that the dogfighting is won solely by skill rather than any inherent advantage(s) of the planes.

(NOTE: Jon doesn't yet know *exactly* what will be included in the RAS 2 release beyond the technical capabilities of the engine. Jon has a master plan, but time constraints may result in some gameplay features being held back for a later update to avoid releasing a buggy game.)


That said, Jon's been working with a preliminary batch of models, textures and stuff from his pet artist and using it as placeholder art. Some of this stuff dates back about two years and will be added to -- with some of the existing stuff enhanced -- once the game's core code is ready to rock.
