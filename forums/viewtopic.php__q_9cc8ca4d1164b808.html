maddog wrote:Hi,
I am trying to log on to multiplayer and I need the ISP log on number and they ask for the server password. HELP
Thanks Alex


I think there's some confusion here: there's no ISP logon number requested in our games.

I suspect it's asking for an "IP Address".

When you type a website address into a web browser, that address -- e.g. "smallrockets.com" -- gets looked up in a kind of global phone book (a process known as a 'DNS lookup') and converted into an IP Address. E.g. "80.189.92.2".

This is the actual 'phone number' of the computer you want to connect to and is what the internet uses behind the scenes to identify *every* computer on the internet. Unfortunately, for many boring reasons, there aren't quite enough unique IP Addresses as there are computers on the internet, so many consumer ISPs won't give your computer a fixed IP address. They'll give it a new one every time it connects instead.

This makes it difficult for multiplayer games to work over the internet, which is why services like GameSpy Arcade exist to get around the issue. If you are unfamiliar with networking, I strongly advise using GameSpy Arcade to connect to multiplayer games on the internet.

Re: GameSpy

by stimarco on Tue Aug 28, 2007 11:09 am

Destry wrote:Two comments: 1) You mean if I were to ask someone to "meet" me on the RAS Pro server LAN, I would open up my computer to a virus or spyware/adware and the like?


Only if you have managed to connect the computer running the RAS Pro server program to the internet. Usually firewalls, NAT translation and other tricks are in place courtesy of your internet service provider. (Chances are, the box you use to connect to the internet runs its own firewall software.) You need to know how to tell these various elements to let the RAS Pro server talk to the internet at large before anyone will be able to see it.

That's why we don't recommend doing so if you're not familiar with the technology. Most people have no idea how to do all that stuff in a way which keeps hackers and other undesirables out of their computer.

2) I tried going to Gamespy, but I have NO clue where to start....do I go to "PC", and if so, where then...there seems to be no where to log into a game in progress.


I'm not sure. I must confess, it's been a long time since I've played any arcade games and I haven't even installed GameSpy in some years.

Have you read the manual or checked the help guides? I think you first need to ask it to look for installed games on your system, then it should offer you the option (somewhere) to connect to suitable servers. (I think GameSpy calls each server a 'room'.)

Do note that Red Ace Squadron isn't a big-budget game like Half-Life or Halo; it's quite possible that there literally isn't anyone else online playing RAS at the time you connect. In which case, try again later, or post a "wanna play?" message to the forums to arrange a time.
