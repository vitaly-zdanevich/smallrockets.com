**** FAQ: Tweaking the JOYSTICK.INI File ****

(Added 30-NOV-2005. Last updated 02-DEC-2005.)


This FAQ applies to:

    * Master Of The Skies: The Red Ace
    * Red Ace Squadron
    * Red Ace Squadron Pro



Q: Why would I want to do this?

A: The "joystick.ini" file tells our "Red Ace" games how to 'read' your joystick. If your joystick seems to be only partially working, tweaking this file may help you get it working better with the game.


Q: What else should I check first?

A: Joysticks can sit in warehouses and shop shelves for a very, very long time. This often means that any software that comes with the joystick may be very out of date. If you find you're having problems with your joystick in other software too, we STRONGLY advise looking for newer, updated 'driver' software for the joystick. (For example, some old Logitech drivers will cause Windows to crash completely in some circumstances.)


Q: "Driver"? What's a "driver"?

A: A "driver" is a program -- a special type of computer program -- that acts as an interpreter between Windows and the device the driver was provided with. Drivers are everywhere, without them, Windows wouldn't know how to talk to your hard disk, your digital camera, your mouse, your keyboard, the sound chip, the video chips -- you name it! A joystick is no exception to this rule: if it's something you can hold in your hand and add to a PC, it must have a driver.

Windows itself comes with some drivers for common types of hardware already, but these drivers are often very basic and only support a minimum of features, so keep an eye open for updates and new versions. You'll find frequent driver updates for video chip drivers, sound chip drivers, motherboards -- the big circuit board everything else plugs into -- and more.

Do NOT update a driver unless you believe you need it; if your PC is working fine, updating a driver can sometimes make things worse! This is especially true for older hardware.



Q: So, how do I tweak the "joystick.ini" file?

A: First, you need to find the "joystick.ini" file. Open up Windows Explorer and look for the Program Files folder. This is usually on the same drive you installed Windows onto and on most PCs, it'll be hard drive labeled C:.

Open this folder. Windows will usually get paranoid and suggest that you're doing something very, very naughty. You are: "Program Files" is the folder in which all your computer programs are installed, so please be very careful.

Tell Windows that you really do know what you're doing and look through the list of folders. You're looking for the one named Small Rockets. Find it and open that folder.

Now you need to open the folder for the "Red Ace" game you want to tweak. Open the folder corresponding to that game. For "Red Ace Squadron", you'll want the folder with that name. (Note: "Red Ace Squadron Pro" uses the same folder name as "Red Ace Squadron"!)

You should now see a bunch of files. A few of them will have ".ini" endings. Look for "joystick.ini".

Right-click on "joystick.ini" and choose "Copy" from the menu. Now, click on an empty part of the window and click "Paste". This will create a backup copy of the "joystick.ini" file called "Copy of joystick.ini". Don't mess with this file! If you make a mistake, you can always delete the messed-up "joystick.ini" file and rename the copy to replace it.

Now, we need to open "joystick.ini" so we can edit it:


    1. Hold down the Shift key on your keyboard.
    2. Keep the Shift key pressed and right-click on the "joystick.ini" file.
    3. Choose the "Open with..." option on the menu. A list of programs will appear.
    4. Scroll down the list until you find "Notepad".
    5. Click "Notepad" and ensure the "Always use the selected program..." box is ticked.
    6. Click the "OK" button. Notepad will open and display the file.


You should now see something that looks a lot like this:

Code:

[Player1Roll]
sensitivity = 0.5
axis = 1
type = joystick

[Player1Pitch]
sensitivity = 0.5
axis = 2
type = joystick


(etc.)


Every joystick has two kinds of control. "Axis"-type controls are those which describe a range of motion. For instance, moving the joystick up and down corresponds to "Axis 2" (the 'pitch' control in the list above.) A "button"-type control is either 'on' or 'off'. Buttons are usually pretty obvious: a fire button would be a "button"-type control. However, the 'hat' feature on some joysticks may also be implemented as a 'button' too.

If you're having problems with your throttle -- this is by far the most common bug report we get regarding joysticks -- you'll need to find the section below:

Code:

[Player1Throttle]
sensitivity = 1
axis = 3
type = joystick


Note the "axis = 3" line. This is the culprit.

This illustrates one of the most irritating problems with Windows and joysticks: there are no cast-iron standards defining which axis should be assigned to which feature. Even buttons are often fairly randomly assigned. About the only axes we can rely on are 1 and 2, for up/down and left/right respectively. Beyond that, we're guessing!

The fix is to change the axis number -- change it to 4 to begin with -- and save the file. (Go to File -> Save to do this.) Now try running the game again. If the throttle still doesn't respond, quite the game and try again, but increase the axis number from 4 to 5. Rinse and repeat until you get a response.


Q: I can get it to respond to the throttle, but it's not working quite right! How do I fix this?

A: You will need to change the sensitivity for the throttle.

If the throttle is proving too sensitive, you may need to tweak the sensitivity to get sensible results from it. To do this, you need to tweak this line:

Code:

sensitivity = 1


A good first attempt is to change the '1' to '0.5' and see what effect that has.

If your throttle seems to be working backwards, use a negative value for the sensitivity. "-1" would be a good number to start with.


All "axis"-type entries in "joystick.ini" will have a similar sensitivity entry. If you're unhappy with the way your joystick is currently responding to movement, feel free to tweak any sensitivity options that apply.

Finally, remember to save the file before testing it! If you don't save it, the game won't see the change(s)!
