Hi Bo,

Some of our older titles aren't XP-compatible. Specifically, none of the titles created for us by the "D-Inter" development team in Russia are officially supported on XP as D-Inter are no longer under contract with us.

The affected titles are:

* Hot Chix 'n' Gear Stix,
* Superchix'76

* Kayak Extreme

* Jetboat Superchamps
* Jetboat Superchamps 2

None of these titles are supported under Windows XP. Although we have heard from some customers who say they've manged to get Jetboat 2 working under XP Pro, we have been unable to duplicate their success ourselves.

Our WW1 dogfighting games are both XP-compatible now, but you may need to download the demo again and re-enter the registration key if your current versions is old.

Regards,

by W2K on Wed Jan 05, 2005 12:10 pm

The most likely reason for not running games with Xp/W2k is an incompatible graphics driver. I still use W2k Pro and none of the above described older games ran on my PC. Earlier I had W98 SE installed on the same PC and all the games ran perfectly.

What did I do ? I replaced the graphics driver.

How ?

- Open the system properties (right click on "My Computer" and select properties) / Select the Hardware Tab and then use the button Device-Manager
- In the Device-Manager, expand the section Display adapters, double click on your display adapter
- Select the Driver Tab and use the button Update Driver ... Continue
- Check the box "search for driver (recommended)" ... Ok
- Search location: check the box "Microsoft Windows Update" ONLY (you have to be connected to the Internet !) - wait until the result is presented
- Check the box "Install another driver" (important!) and continue. Now you get a list of drivers.
- Look for a driver that is not from the maker of the graphics controller but from Microsoft. If one is available, install it. Be aware this is only a trial and error solution!
- Reboot your PC and try to play the game

If it doesn't work, go back to the previous installed driver.

For Xp users it's very simple to undo the installation. Go back to the window with the "Update Driver" button. Below you find the button "Roll back driver".

For W2k users: remember the installed driver BEFORE update, or install the proposed driver from the driver search described above without checking the box "Install another driver".

For W2k it works. The result is not the very best, but you can play the games.

Good luck
