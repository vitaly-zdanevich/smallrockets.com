by stimarco on Wed Sep 01, 2004 12:06 pm

Hi Spliff,

Even if the game isn't showing anything on the screen, the code itself is still running. (Jetboat isn't supported on Windows 2000 or XP, unfortunately, so you're not the first to report this.) Since the code itself is running, it is also still accessing its files.

To uninstall it, you will need to restart Windows to 'kill' the crashed game and stop it from hogging its files.

Unfortunately, we have never released any versions of our games on CD. You must have bought the game from a publisher who licensed the games from us and who then added their own installers. (Our own installers always leave an uninstaller option in the "Add/Remove Programs" control panel.)

There's not much I can do to help: we didn't produce the installers for the CD, so we have no idea why they aren't working. It's quite possible, given the age of the games, that the CD predates Windows XP, in which case the installer software probably isn't XP-compatible either.

Assuming the installer is all they changed, you should be able to manually delete the folder for each game (inside your "Program Files" folder) and then manually delete the menu entries in the Start Menu.
