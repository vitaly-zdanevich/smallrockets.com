Hi Rasmo,

we did have a dedicated server in the Uk for RAS. It worked ok, but wasn't 100% reliable, and since alot of our customers were in the US I'm guessing the performance across the atlantic wasn't all that.

We do currently have download and webservers located in the US, and intend to have at least one game server in the US.

With the previous version of the game only one game 'instance' could be run on a server, and this made dedicated servers not very cost effective. On the new version we intend to make it possible to have lots of game instances running on a single server. Which should help things.

How many and how long for? In the end it depends on the populatarity of the game. If its very popular, then we can afford to have lots of servers for a long time.

But the bottom line is that we intend to have more servers at least in the Uk and the Us at launch, and each server will be able to take many games, which should be much better than last time around.
