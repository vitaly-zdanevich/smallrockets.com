Re: RAS Pro - black screen, flickering white triangle

by stimarco on Fri Feb 06, 2009 8:08 am

Hi,

I would prefer these support requests to be sent through our usual system as I have some tools I can use there which are unavailable to me on these forums. Another issue is that I have no way of linking your forum ID with our customer records database. (We keep our forums entirely separate from the rest of the site for security reasons.)

I'm concerned that the game doesn't appear to work at all on your PC. It should, as our "Red Ace" titles should be XP-compatible. For this reason, I'm still suspicious of the drivers...

If all you've done is installed the default drivers from the CD, you may need to update rather more than the graphics chip. Motherboards are extremely complex today. There are often layers and layers of circuits, sandwiched together sometimes more than six levels deep. There will be drivers for the hard disk controllers (sometimes more than one type if it has both IDE and SATA support), memory management, networking, graphics, audio, USB, PCI cards, SLI support and plenty more. These are high-performance components, so it's rather like designing a car with a dozen, powerful sports engines, each from a different manufacturer, and all of which have to be kept in sync.

A bug in any one of these could cause any number of increasingly bizarre side-effects, so I strongly suggest checking AMD's website for updates to all your motherboard's drivers. You should also keep checking the manufacturer's site on a regular basis for the first year or so as updates are likely to be frequent initially.

I hope the above is helpful. If not, please do get back in touch.
