The easiest way to play Red Ace Squadron online is through Gamespy Arcade. This is a program that acts as a multi-player match-up service.
You can download a trial version from http://www.gamespyarcade.com
Once this software is installed on your system start it up and log into it. When it has loaded completely go to the File menu at the top of the screen and select scan for games.
This will scan your system and find where you have Red Ace Squadron installed.

Once the scan has finished close down the software and restart it.
Now when it loads you should see an icon for Red Ace Squadron on the menu bar to the left.
Click on this and it will take you to a lobby area for the game.
This lobby area will display all the current available servers to play on, it will also allow you to chat with other players and set up games.

To join a game, highlight it in the list of servers and click join.
The Gamespy software will automatically launch the Red Ace Squadron software and you will be flying and shooting down bad guys in no time.

It's quite possible that the ICF, or Internet Connection Firewall that comes as part of Windows XP is blocking you from connecting to a server.

To see if it's on and to adjust the settings, go to START/CONTROL PANEL/NETWORK CONNECTIONS.

Click on your connection which opens little window. From there, click on Properties in the lower left corner. This opens another little window.

Then click on the "Advanced" tab on top, and it will show you a window where you can check or uncheck to enable or disable the firewall.

To enable it but allow certain types of connections to get through, click on the Settings button in the lower right corner. In the window that opens, you can click on the various tabs across the top and see the various things you can check to allow, or uncheck to block.

Maybe fooling around with these settings will do the trick.

Otherwise, you could just disable the ICF completely and see if that does the trick

Establishing your own Server

The easiest way to play online if you do not know a server IP address is to use the Gamespy Arcade program.

Gamespy Arcade is a match-up service for multiplayer gaming. You do not need to subscribe to it, but you do need to set up an account. The best thing to do is to download the trial version available on the Gamespy website (there is a shortcut to this in the Start Menu Group for the game). Once you have it downloaded and installed it will ask you to set up an account, follow the steps and then the game will scan your machine for the games it supports to see if you have them installed.
Now it should pick up Red Ace Squadron as being installed. It will show up on the left hand menu. Now all you need to do is click on the Red Ace Squadron Icon and you will be taken to the lobby which will show you all the game servers that are running and that you are able to join. You will also be able to chat to other people that want to play the game.

The Red Ace Squadron server is the program you need to run if you wish to host a server yourself. For Example, if you run this program and then launch Gamespy you will see your game in the lobby. Now the server will run as a separate entity to the game, so if you want to connect to your own server, you would need to run the normal game exe as well, type in the IP address of your machine (or use Gamespy) and you should be able to connect to it.

The ports that you need to open are the following:

If you are running a server you need to ensure port 6112 is open both ways for TCP and UDP.
If you are just running the client you need to ensure port 6113 is open both ways for TCP and UDP

Direct X for Direct IP play requires that the following ports be accessible:

TCP UDP
47624 (Outbound) 2300 - 2400 (Outbound)
2300 - 2400 (Outbound)
2300 - 2400 (Inbound)



Possible Zone Alarm Problems

The only instance I have any experience with is where zone alarm was causing my internet connection to dis-connect. The solution was to find the file called "vsdata95.vxd". This file is created by Zone Alarm and is usually found in the folder C:WindowsSystem. Do not delete the file but just rename it to vsdata95.vxd.old and reboot your system. If you find that solves the problem (which it did in my case) just leave things as they are. I haven't found any negative effects on the operation of Zone Alarm. After that, you're on your own. You might try e-mailing Zone Labs to see just what effect if any the omission of that file might have on the operation of Zone Alarm.
