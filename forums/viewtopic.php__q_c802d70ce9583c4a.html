I believe this is something they intend to include in the forthcoming sequel, Red Ace Squadron 2.

Before you do anything else, make sure your joystick is calibrated correctly in the Windows "Game Controllers" Control Panel. You should also make sure each joystick function is being recognised correctly by this Panel as the game relies on Windows for joystick handling.

It it's working properly, it may be necessary to edit the appropriate 'ini' file in the Red Ace Squadron program folder. (Usually found in: "C:\Program Files\Small Rockets\Red Ace Squadron".)

The files in question are "joystick.ini" and "joystickkeys.ini", depending on which scheme you're using in the game. In these files, you can change the varous axis, buttons and keys used for each game function.

I can't test this as I don't own a joystick of my own, but looking at the .INI file suggests you can replace the "axis=3" line with one that points to your joystick's throttle axis. (Experiment with different numbers to find out which one it is.)

I'm not sure it's possible to assign buttons to the throttle. It looks like it's hardwired to either keyboard "upkey / downkey" entries, or a joystick axis. You could try using the "joystickkeys.ini" file and replacing the throttle entry to read like this, but this is only a guess; I honestly have no idea if this will actually work:

[Player1Throttle]
sensitivity = 1
upkey = 3
downkey = 4
type = joystick

Replace the '3' and '4' with whichever button numbers you prefer to use for this function. Also, make sure that any references to these buttons elsewhere in the .INI file are replaced or you'll get very strange behaviour. And remember to backup the original file first, as well as choose "Joystick + Keys" as the control method in the game.

Again, I have no way to tell if it's actually reading the buttons, but the game didn't crash when I tried the above, so let us know if you have any success with this.
