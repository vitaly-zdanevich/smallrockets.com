License code not working?

[Created: 07-JAN-2011.]

Firstly, please ensure you really did buy the game directly through our own website! If necessary, check through your email archives and backups and see who the original purchase confirmation email came from.

IMPORTANT: We cannot provide any licensing or technical support for games that were installed from another website, or from a CD-ROM. If you did not buy the game directly through our site, the company that sold you the game is responsible for providing customer service to you. We have no access at all to other publishers' customer records or license code generation tools.

If you are certain you bought the game directly from us, and are having problems unlocking it, read on...

There are a couple of possible reasons for this glitch, most of which are too technical to bore you with. However, one possibility is that your Windows Registry is corrupted. This can be due to a particularly nasty crash, or because your computer's hard drive is starting to fail. (Many of our customers are running our games on older PCs, so this isn't as unlikely as it seems. If you're still running Windows XP, it's likely your PC's hard drive is getting old. Most consumer-grade hard drives have an expected lifespan of just three to four years.)

The Solution:

1. Uninstall the demo.
2. Restart Windows—please do not skip this step!
3. Download the current version of the demo from our website. (Jon's been updating the installers over the last couple of months, and this includes some fixes.)
4. Install the demo, but do not unlock it yet!
5. Restart Windows. (Again, please don't skip this step!)
6. Try unlocking the demo now.

If this doesn't work, you may need to download the current version of our "SRKEY.EXE" program from this page. (The link is in the second of the "Top Tips" boxes.)

"SRKEY.EXE" is the program that handles the license codes for all our games. The latest installers should already include this latest version, but not all our games have been updated with this installer as yet.

Overwrite the existing versions of the "SRKEY.EXE" program in the appropriate "Program Files" folder. The path usually looks something like, "C:\Program Files\Small Rockets\[NAME OF GAME]", but your particular PC's folder structure may vary. (NOTE: On 64-bit versions of Windows, the Small Rockets folder will be inside the "Program Files (x86)" folder.)

If you try unlocking the game again, it should work.

*

If all this fails, and you are running Windows Vista or Windows 7, please check out our Windows Vista / 7 FAQ.

If you are running the 64-bit edition of Windows XP, I'm afraid we don't support that version.

If you have had no success, and you are running the 32-bit version of Windows XP, the problem is most likely to be a corrupted Windows Registry.

There's nothing much we can do about this. A corrupted Windows Registry is usually best 'fixed' by reinstalling Windows on your computer. However, as many of our customers are likely to be using older PCs, it's worth pointing out that a corrupted Windows Registry can be caused by a faulty component in your PC, such as a broken RAM chip, or a failing hard disk. You should check your PC's health more regularly as it gets older.
