I'm currently running tests on all our titles to see which ones will need modification for Vista. (Of course, the fact that I suck at arcade-type games makes it harder to tell if the game works _all the way through_.)

I'm not sure if RC2 handles upgrades properly yet; I've read mixed reports about the upgrade process' stability. I chose to install it on a new partition instead.

By all means try it, but please back up your important files first, just in case.
