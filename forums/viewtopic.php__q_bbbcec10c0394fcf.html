We're aware that some versions work differently to others. We're also aware that some people can get some of the games running without problems. The problems are deeper -- things like DirectX support and the like -- where specific combinations of hardware cause crashes or the game simply fails to run.

The old installer was also much simpler as it was designed for the old MS-DOS-based versions of Windows. Unfortunately, it failed to take into account some of Windows XP's security features. Basically, it worked, but only if you have the default Windows XP installation. If you're using proper Administrator and User security levels, the game falls over. (It also didn't like some OEM Windows XP installations.)

So yes, we know it works for some people, on certain machines, with certain components. Unfortunately, the games don't work for _all_ people, on _all_ machines, for _all_ components! That's the problem! We can't change anything in the game itself to fix the problems.
