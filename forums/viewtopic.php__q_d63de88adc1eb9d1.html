I've said this before and I'll say it again: drivers, drivers, drivers! In 99.999% of cases, updating your drivers will fix the problem.

This is particularly true with Windows XP SP2, which is a lot less forgiving of drivers that use nasty tricks or hacks to do their stuff. (In other words: lazy programming isn't enough any more. You HAVE to get it right, or SP2 might think of it as a security threat.)

We recommend that _anyone_ who has installed SP2 makes sure that *all* their drivers -- video, audio, chipset, network card, etc. -- are updated.

Note that in some cases, SP2 will actually _replace_ drivers it knows it won't get on with during the installation process with the default Microsoft ones. These drivers offer only basic functionality and may not support all the features of the hardware, supporting just enough to let Windows boot up and run.

The primary culprits are usually video and audio hardware drivers. The more complex the hardware, the trickier it is to write drivers for it, so if you ever decide to build a PC just for games, go for simple, tried-and-tested hardware. Stick to hardware that's a generation behind the cutting edge, as the drivers will have had much more testing.

One possibility that springs to mind, given the reported symptoms, is that you are using a controller designed for older PCs. Some older joysticks seem to have trouble running on newer PCs, especially if they use USB connections, since their drivers are now running too quickly. In most cases, you can just download an updated driver from the company's website. (Logitech have a few affected models, for instance. Hmm. Your Audigy 2 drivers predate WinXP SP2, so they need to be updated. I have the Audigy 2 Platinum eX in my home PC and I know there are more recent drivers on their website.

However...

You're running the game on what appears to be a server. You have a striped RAID 0 hard drive array, a bunch of stuff on a SCSI card, _four_ optical drives and a shedload more hardware in that beast than is sensible for a games PC.

The SATA RAID chipset driver is dated 2003. The Promise SCSI card driver is dated 2002. This means these drivers are _much_ older than Windows XP SP2 and therefore I would advise an update.

That said, a number of the motherboard chipset drivers also predate SP2. I'm pretty sure there are newer drivers available for that mainboard, although one problem with server drivers is that they tend to see far fewer updates and releases than general purpose motherboards.

Also, if you have Intel's "Application Accelerator" installed, make sure that's up-to-date too.

Another check to make is to look in your BIOS settings and make sure there aren't any wasted IRQs. There's a limited number of these and with all the hardware you have in that box, it's possible that there might not be enough to go around. (This tends to be a problem only when the PC is being really stressed. Such as when playing a 3D game.)

A final resort is to try disabling individual hardware components one at a time to see if one of them is the culprit.
