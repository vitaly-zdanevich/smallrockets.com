lagging

by Frank Parkinson on Thu Apr 24, 2003 8:24 am

Lag experienced on Red Ace Squadron would only occur during multiplayer games - and this would be down to the bandwidth availability between your machine and other competing players.
If you're talking about both games running slowly on your machine in single player mode, then this is likely to be attributable to your own hardware setup, if you wish I can look into it for you.
You'll need to provide me with a current system report, please follow the instructions below and I'll get right onto it:

1. From the Windows Task bar click on START

2. Select RUN from the drop down list that now appears

3. Type DXDIAG in the command line window that opens when you click on RUN.

4. The application that now runs allows you to view the current hardware settings of you machine AND save a report out to your hard drive by clicking on the button entitled SAVE ALL INFORMATION.

5. Once you have the report, attach it to an e-mail and send to support@smallrockets.com

Note:
If you receive an error when attempting to run DXDIAG, it could be that you're using an older version of DIRECT X.
All Small Rockets games require DIRECT X Version 6.0 or above and you would
have to upgrade in order to run the game.

The latest versions of Direct X can be downloaded from http://www.microsoft.com/directx

Frank Parkinson
