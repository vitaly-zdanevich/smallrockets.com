I assume you're referring to RAS Pro. In which case, it's the version of the networking code. You need to be sure users at each end of a networked (or internet) game are running the same version of RAS Pro. Most will be.

Users of the original "Red Ace Squadron" game will have an older version of the networking code, which cannot talk to RAS Pro.
