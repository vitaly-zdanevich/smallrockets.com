"Art Is Dead" News.

Posted: Sun Jul 30, 2006 2:38 pm
by stimarco
We have received a number of reports regarding this game and it is now clear that there is a major issue with Windows XP Service Pack 2 that prevents this game from running.

We have investigated the problem and it is now known that the fault lies in changes that Windows XP Service Pack 2 made to the Windows XP operating system -- specifically those elements that were required by those (admittedly few) games relying on light guns. These changes prevent important parts of the game from running. A fix is not a trivial process.

One possibility we are investigating is replacing the core components of the game with new ones currently being developed for our forthcoming "Red Ace Squadron 2" game. This would also give us an opportunity to ensure the new code is robust and general-purpose enough for use in other games, as well as opening up the possibility of updating some of our other titles in a similar way and extending their lifespan.

I have no firm ETA on this as it's a major undertaking and we already have "Red Ace Squadron 2" to contend with. As the cliché goes: "Please bear with us. Normal service will be resumed as soon as possible."
