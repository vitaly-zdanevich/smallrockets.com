LAN Gaming HOW-TO: Multiplayer gaming over a local network

Posted: Thu Oct 29, 2009 2:06 pm
by stimarco
Hi readers,

We get a lot of requests through our support section asking us how to play Red Ace Squadron Pro over a local network. I've decided to write this backgrounder piece to explain the basics.

Multiplayer RAS Pro Gaming over a LAN.

If you’re having trouble playing a RAS Pro game over a home (or office) network, you may wish to read through this...

Networking is a tricky subject, so if you don't understand what follows, ask a friendly computer guru to help out.

*

Our games follow a standard “host and guests” model, with a single server playing host to one, two or more guests. (This model is known in the industry as “client-server”, with the clients being the guests.)

This is how most stuff on the Internet works: The website you’re reading this on sits on a web server, which is just a specialised PC. Your PC is the ‘guest’ in this case; our web server is the ‘host’.

To play RAS Pro over your own network, you need to run the "Red Ace Squadron Pro Server" program on one of your PCs. This server program acts as the ‘host’, while each copy of the game itself is a ‘guest’.

(NOTE: To avoid having to dedicate an entire PC to host duties, the same PC that runs the server can also run the game itself, becoming its own guest. If you do this, I advise running the server on the fastest of the PCs.)

Now comes the tricky part: telling each PC where the server is!

Computers prefer to do everything with numbers. On almost every network today, that means each computer has its own numeric address. This is called an "IP Address" and is the Internet's equivalent of a phone number.

(The "www.smallrockets.com" address you see at the top of your web browser is converted into an IP Address by your computer; the textual address is just for us humans. Our web server’s IP Address is: 69.10.132.242. Type this into your web browser and you’ll see our website appear, as if you’d typed in the name instead.)

Each PC on a network must have its own IP Address. This address is usually given to the computer when it’s switched on and varies from network to network, so I can't tell you what the address will be for your PC. They're usually of the form, "192.168.x.y", or "10.x.y.z". (Exactly what the "x", "y" and "z" values are depends on your network's settings.)

You will need to know the IP Address for the PC which will be running the Red Ace Squadron Pro Server program. There are a few ways to find this out, but the easiest one for me to describe—I can't put screenshots into this reply—is as follows:

1. Hold down the Windows key (which normally opens the Start Menu) and press 'R'.

You should see a small box asking for a command.

2. In the command box, type: cmd

Another window should now pop up. This will be mostly black, with white text.

3. Type the following command: ipconfig /all

This should bring up a new window looking rather like this:


(NOTE: You will see an entry for each network device your PC has, even if it's not being used, so you may have to scroll through the results to find the relevant entry. Most PCs today have at least one "Local Area Connection" connector for attaching a network cable, while laptops will often have a wireless network device too, shown as a "WiFi", "WLAN" or "Wireless LAN" connection.)

4. If your PC is connected to the network using a network cable, you should look for the "LAN" or "Local Area Connection" entry. The only information you need is the "IP Address" entry.

5. If your PC is connected to the network using a wireless connection, you should look for a "Wireless LAN", "WiFi", "WLAN" or "Wireless Local Area Network" entry. Again, the "IP Address" entry is the important one.


You can now tell the other PC to use this address to connect to the server.

(NOTE: If you're also running the game itself on the server, you can use a special IP Address: 127.0.0.1. This is known as the "loopback" address.)

If the two PCs fail to see each other after all this, you may need to adjust the settings on a "firewall" program. These programs act as gatekeepers, or night-club bouncers, keeping out unwanted guests, such as hackers. You will need to open up a "port" or two to allow the PCs and server to talk to each other.

We have a section in our support area which covers firewall ports, here.

I’ve only touched on the most common issues. In 99% of cases, this should be enough to get you playing.
