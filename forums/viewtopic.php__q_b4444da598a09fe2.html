I have experimented and things seem to work by changing the game compatibility mode in XP. Right click on your desktop game icon and go to the top and click on "compatibility". Now check the box that says "Run this program in compatibility mode for".... now select Windows 95. If that does not work for you go to the next option Windows 98/ME. I was able to run both of this in the Windows 95 mode. Please keep in mind that your own computer resources DO have something to do with it too... such as graphics card, accelerators, etc.

At least this gives you a bit of an option to TRY to see if it will work for you.
