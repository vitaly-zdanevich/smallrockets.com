Beta of Tower of the Ancients Redux

by jonathan on Thu Jul 22, 2010 9:55 pm

Hi,

we're proud to release 'Tower of the Ancients Redux'. This is basically the original Tower of the Ancients game running on the latest Small Rockets technology. Most of the changes and improvements are invisible - but what this really means is that SmallRockets now has a technological base to start releasing updates and new games.

Features of beta

* Works at any resolution - and runs full screen or windowed
* Fully compatible with XP, Vista and windows 7
* Fully cross platform - although this release is just Windows
* Updated UI allows for mouse and keyboard control

The only significant feature from the original missing from this new version is the 'hand of god' sequence when the game is over. It may go back at some point - but there's no rush to at the moment.

If you find problems - strange behavior, crashes, installer issues etc - please describe the problem and how you managed to create it on this forum.

You can download the beta from..

http://downloads.smallrockets.com/downloads/tower/sr-tower-redux-demo-beta.exe

Thanks,

Jonathan
