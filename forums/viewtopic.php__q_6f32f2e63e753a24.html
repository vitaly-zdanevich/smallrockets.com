Hi Geometrian!

"DFF" stands for "DIVE File Format" and is a legacy of the original game engine on which our own games are based.

Jon—and most of the Small Rockets crew—were originally employed by the people who created "Renderware", a graphics rendering library sold to other developers to make building games easier. The version of Renderware that became most popular in the early years of this century was "Renderware 3", which used many components derived from a game called "SubCulture", released in the late '90s. The original "SubCulture" game engine was named "DIVE", hence "DIVE File Format". Renderware—and its owner, Criterion Software (now part of EA)—has long since vanished from the market.

Indeed, one of the key problems with maintaining our games now is that the tools needed to run the conversion code and build the games requires versions of Windows and development tools that have been unavailable for some years. (Most of our games were built using Visual Studio 6, which was discontinued in 2002. Visual Studio 6 does not run on the later versions of Windows XP, let alone Windows Vista or Windows 7.) This is one of the main reasons for Jon building the new engine and tools. It's also why "modding" tools are not viable for our existing games: the tools and libraries needed to create these is no longer available. The new engine won't be tied to vendor-specific technologies and tools as its predecessor, making maintenance and updates easier; now that we know how long a game might be on sale for, it makes more sense to take this approach.

I didn't realize there were tools to convert .dffs - could be kinda handy in the future. Any weirdness in the models is either due to the converter or how the artist created - because the .dff format is really a very simple indexed triangle format with some bits on the side (for vertex morph animation + frame hierarchies).

New engine has its own model format, which .dffs can convert to. Having it import from a standard format tho - would be nice for modding. So definitely worth looking at .obj. New engine does support png - and that would be much better for quite a few of the textures and images used.
