Hi,

I think I answered your query via our SR Support system.

Our games _should_ run fine on DirectX 9c. In fact, we've not heard of anyone else having similar problems, so I'm inclined to suspect there's a problem with your PC.

While Windows may be pointing the finger of blame at the graphics card (which is certainly plausible as both our shoot-em-up games use graphics card features that are rarely used by mainstream 3D titles), it's quite possible that the problem is caused by something else.

In any case, it sounds suspiciously like a memory leak bug: something is allocating memory to perform a function, but not releasing it back to Windows when it's done. Do this often enough and Windows effectively runs out of memory. And so does the game.

Where that memory leak bug _lives_ is a difficult question to answer. I can only suggest going through _all_ the drivers on your PC to see if there are updates available. Even joypad drivers have been known to have bugs.

The games themselves are not, however, at fault. They've been out for far too long already for such a bug to have gone unnoticed.
