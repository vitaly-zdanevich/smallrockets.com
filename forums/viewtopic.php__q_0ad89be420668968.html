Muscle Car 76 won't load

by Rob Charlish on Fri Jan 11, 2002 5:57 pm

This is almost definatly a driver issue. What you need to do is grab the latest videocard drivers for your videocard. If you do not know which videocard you have or where you can get drivers from send me a DXDIAG report from your machine to our tech support email and I will point you in the right direction.

To create a DXDIAG report you need to do the following.

1. From the Windows Task bar click on START
2. Select RUN from the drop down list that now appears
3. Type DXDIAG in the command line window that opens when you click on RUN.
4. The application that now runs allows you to view the current hardware settings of you machine AND save a report out to your hard drive by clicking on the button entitled SAVE ALL INFORMATION.
5. Once you have the report, attach it to an e-mail to techsup@smallrockets.com


Thanks
