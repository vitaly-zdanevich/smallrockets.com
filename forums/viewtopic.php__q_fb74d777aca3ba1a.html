The problem with screenies is that they won't look any different. Jon's been focusing mostly on behind-the-scenes stuff like rewriting the old user interface code and improving the network subsystem, since these are the areas most affected by changes in Windows Vista.

RAS and RAS Pro are just about playable in Vista, but the front end menus seem to be affected badly by the fancy "Glass" user interface. The game's menus flicker so much and take so long to appear and change that they're not really useable. Which means Jon has had to rip out all that old code and rewrite it for RAS 2 and will probably have to refit RAS Pro with this same code to make it Vista-compatible.

On the plus side, only a few of our older games fail to run at all under Vista, but there are a couple of titles which will need some work. The "Free Zone" games even seem to run more reliably under it. Jon needs to get these sorted soonish as otherwise we'll be inundated with support requests.

I'll keep pestering Jon until he relents. I'd like to see a movie or something myself, if only to have something new to post in the News section.
