Hi,

"Art Is Dead" was an oddity we produced way back when. It's probably the only game still being sold for PCs that supports "light guns". Light guns never really caught on, so I suspect the bugs we're seeing reported on it are more to do with the various hardware drivers not supporting features that these devices required. (The lingering death of the CRT isn't helping, since light guns relied on the cathode ray tube's scanning electron beam to do their stuff. Light guns won't work at all on LCDs.)

I'm afraid this all seems to have come to a head in Windows XP Service Pack 2. Since "Art Is Dead" never sold that well, it's not likely that a patch will surface any time soon. It's a very old game, designed for a niche market in the Windows 95/98 era. Five years is a long time for any game to sit on the shelves.

Since the game did work on Windows XP until the service packs started appearing, it may be that the fix is a trivial one. (Just take out the light gun code.) However, the programmer who wrote the game is no longer working for us, so it may not be as easy as that sounds. Personally, I suspect this one will be appearing in the freebies area sooner rather than later.

My apologies for the inconvenience. I can only suggest trying the various backwards compatibility options on the game to see if they solve the problem. Alternatively, try dual-booting with Windows 98 or Windows ME.

Regards,

--
Sean Timarco Baggaley
SR Support.
