VISTA & WINDOWS 7 COMPATIBILITY

by stimarco on Sun Apr 08, 2007 3:00 pm

[UPDATED: 10-MAR-2012.]

What's New?

Added bit about support for virtual machines, such as Parallels and VMWare for Mac.

Summary.

We cannot fully support our current catalogue of games on Windows Vista or Windows 7 at present, but we are working on it. We are aware that this is not a good situation to be in as we're having to turn customers away. We are working on the problem! (Slowly, I admit. SR is a part-time operation at the moment.)

Having trouble unlocking the game?

Try downloading the updated version of SRKEY.EXE, here. Some older versions of this seem to dislike Windows XP Service Pack 3, as well as Vista and 7.

Note 1: our games are supposed to register the ".SRK" file type with SRKEY.EXE. If Windows is asking you "Which program should I use to open this file?", you may need to re-install the game as follows:

1. Uninstall the demo;
2. Restart Windows;
3. Reinstall the demo, but do NOT attempt to unlock it yet;
4. Restart Windows (yes, again.)
5. Unlock the game.

Note 2: if your computer is a particularly old model, its hard disk may be failing. This can cause data to become corrupt. If the Windows Registry—a special database Windows uses to keep track of what's what—is affected, this can cause all sorts of strange behaviour. Unfortunately, the only 'fix' for this is to replace your hard disk and reinstall Windows from scratch. (This is, incidentally, why should always keep backups of your important documents. Right! Lecture over...)

Can I run your games in a virtual machine like Parallels, VirtualBox, or VMWare?

This may work, but we don't recommend it.

Like pretty much every other games developer, we cannot officially support running our games in virtual machines or emulators such as Parallels or VMWare (Mac / Windows ) or VirtualBox (Mac / Linux / Windows). These programs have to do some very intricate translations to support accelerated 3D graphics, including translating Direct3D calls into OpenGL ones when running Windows games on non-Windows platforms. This is like translating French into Japanese: something is invariably lost in translation, so the graphics code is often designed primarily for basic applications such as Microsoft's Office suite, rather than for high-performance games.

The situation is slowly getting better, but supporting these applications, as well as the myriad graphics cards out there, would be a nightmare for a small development company like Small Rockets, so, while we're not going to claim that our games won't work on these at all, we aren't going to go out of our way to support them.

Therefore, if it is an option, please just run our games in a Windows partition instead. (E.g. using the "Boot Camp" feature on Macs.)


I wanna play your games now! NOW! NOW! NOW!!! GIMME!

We have received comments from our customers who have successfully managed to play our games on Vista. We cannot guarantee that these suggestions will work with your particular PC as we've had mixed success with our own computers. Nevertheless, here's the suggested process for installing and running on Vista and Windows 7:

1. Install the game in "Compatibility Mode".
- Right-click on the program in the Start Menu, or its icon on the Desktop, choose "Properties", and access the "Compatibility" tab. Set the topmost option to "Windows XP (Service Pack 2)" and ensure its check-box is ticked.
vista-compatibility-mode.png

2. Disable the "Aero" theme.
- Vista will restore the theme when you exit the game.

3. Disable the desktop composition feature.
- Again, Vista will restore this when you exit the game.

4. Run the program as an Administrator.
- without this, you'll have problems unlocking our games, although the game demo should run normally.

5. Repeat Steps 1-4 on the "SRKEY.EXE" program.
- This program does the actual unlocking and can be found in the Program Files \ Small Rockets \ [NAME OF GAME] folder.


TIP: The attached image shows how the "Compatibility" tab should appear once the changes are made.

You will also need to perform the same steps on the installed game itself too. You'll find it in "Program Files / Small Rockets / [NAME OF GAME]". The "Program Files" folder is usually on your boot drive -- C: for most people.

Finally, there are two "Program Files" folders in 64-bit versions of Windows. If you're running a 64-bit version of Windows Vista or Windows 7, our games will install to the "Program Files (x86)" folder. (The "Program Files" folder for these versions of Windows is for 64-bit applications.)

*

As long as you perform the steps above, you should be able to run most of our games without much stress, although you may still see some flickering and the odd glitch on menu screens. Nevertheless, the need to jump through all these hoops is unacceptable to us, hence we are not officially supporting Vista for any of our un-rebuilt games. The same goes for Windows 7.

I should point out that Vista and Windows 7 do have one notable advantage over XP: they seem a little more compatible with the games in our "Free Stuff" area than the current version of Windows XP with Service Pack 3 installed.



Why are SR games not officially supported on Vista or Windows 7?

Our games are ancient by computer game standards. Even "Red Ace Squadron Pro", our newest game, was only a relatively minor update to "Red Ace Squadron", adding some new networking and multiplayer features, but retaining its underlying game engine. This component dates way back to 2001. As a result, our games are only fully guaranteed to work on Windows XP and some earlier versions of Windows.

Some of our games are about a decade old and supporting them is becoming a major problem: the tools used to create these games went out of production years ago and will only run on older PCs running older versions of Windows. We have already had to drop support for a number of games we did not develop ourselves. (These games are in the "free stuff" area now. They will *never* be updated again and we keep them on our site solely for those who still have PCs of the appropriate vintage.)

Many of Vista's features weren't even in on the drawing board when our games were conceived and neither our designers nor our programmers could predict that far into the future. Vista added a number of deep, architectural changes that make it nigh-on impossible to modify our current games to run on Vista; the original game engine and its tools are no longer fit for purpose and must be replaced. Jonathan, who owns Small Rockets, is working on this mammoth project.

Most of our games do run well in Windows Vista and Windows 7—the latter seems to give the best results—but they require "Compatibility Mode", with only a couple of games showing glitches. (See below for more detail on the "Compatibility" options in Windows Vista and Windows 7.)

However, the installers need updating and one game did crash: the original "Natural Fawn Killers". Jon is not yet certain what to do with this game.

What Small Rockets are doing about it.

Jon has spent the last couple of years building a replacement game engine and suite of tools. The intention is to replace the old components in all our current on-sale games with these new components. Nobody, that we know of, has ever tried to do this. It's brand new territory. This is closer to the kind of restoration work that went into this stuff, rather than to a straightforward repair or remake.

Thanks to the new engine and tools, our rebuilt games and any future titles will be compatible with Vista and Windows 7. Furthermore, the new engine will make conversion to other operating systems such as Apple's OS X, as well as console platforms, viable at last. The rebuilding process is no small task: each game will be effectively rewritten using the new system; only the original game logic is guaranteed to survive the process unscathed. The new engine also makes some of the original graphics look their age, so Jon is considering creating new graphics for some titles.

The new engine and tools are now ready for their first trial by fire: the rebuilding of "Tower of The Ancients". This game was chosen first because it has a number of unique technical features. Rebuilding these features using the new components should provide a good stress-test for them and highlight any problems. This game is therefore likely to take the longest to convert and Jon is also considering new graphics for the game as the original content has dated badly.

Progress on this updating can be found in our Development Diaries forums. At the time of writing this FAQ update, the game is now approaching an "Alpha test" stage: it's almost feature-complete, but still needs some spit and polish.


What about the "Red Ace" series and the proposed sequel, "Red Ace Squadron 2"?

The sequel to "Red Ace Squadron Pro", which currently has the imaginative name of "Red Ace Squadron Pro 2", will be built on Jon's new engine. As Small Rockets is currently a one-man operation—I only handle customer support—this does mean the process has taken quite a bit longer than planned. Nevertheless, the work is being done and it's progressing steadily, if a little slower than either Jon or myself would like. In addition, Jon needs to work on "quick wins" first: games which don't require anything else, such as graphics or sound effects, to be redone. The improved sales from this first batch will help pay for the extra work needed on the other titles.

These "rebuilds" are a higher priority. The rebuilt versions of the existing "Red Ace" games will probably see some revamped graphics and maybe even some new levels. (No promises; it all depends on available time and resources.)

Most rebuilt games will be made available as a free upgrade to all existing Small Rockets customers. (I.e. customers who bought our games directly from us.) There may be one or two exceptions to this should Jon decide that graphics and levels need to be completely redone. There's also the possibility of completely replacing the original graphics in some games to create a different feel—something currently being considered for "Tower..."


Regards,
