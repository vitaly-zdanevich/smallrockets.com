Hi Carl, This is for if you would like to use the throttle on your joy stick as well. How to get the throttle to work right
on your joystick

The most important thing is to ensure that the joystick is correctly calibrated via the Windows game controllers module

Click on "START"
Select "SETTINGS"
Select CONTROL PANEL

Select GAME CONTROLLERS (also called GAMING OPTIONS on some systems)

There are two "tabs" to the panel that now appears: GENERAL & ADVANCED or CONTROLLERS & CONTROLLER ID’s

For Systems with GENERAL / ADVANCED tabs
On the "General" tab, ensure that your device is reported and identified as working "ok".

To add your device, click on ADD and select the controller from the list that appears.

If your controller does not appear in the drop-down list then you need to install the drivers that came with your device in order for Windows to recognize it.

On the "Advanced" tab, ensure that your device occupies the first available slot (ID 1).

To change the order of any device in this list, simply click on the "change" button and type a new ID number at the flashing cursor position.

Click on "OK" to finish and return to the Windows Desktop.

Once in the game, go to the control options screen and change your default control setting (usually KEYBOARD) to whichever device you wish to use - Gampad or Steering Wheel or Joystick.

For systems with CONTROLLERS & CONTROLLER ID’s tabs
On the CONTROLLERS tab, highlight the controller you wish to use and click the button entitled PROPERTIES.

Follow the instructions on screen to test the controller \ joystick X-AXIS/Y-AXIS movement.

Check all button inputs are registering (corresponding red buttons should highlight on screen when the buttons are pressed on the device)

On the CONTROLLER ID tab, ensure that the device you intend using with the game occupies the ID #1 Slot.

The order of devices can be changed by highlighting any device you wish to move and selecting the CHANGE command button.

Start the game and go to the Controls option page. Select Joystick with throttle. Now shut the game down.
Now go to where you have installed the game to and find the file REDACE.INI, open this file in Notepad or any text editor.
Look for the following lines of text

[Player1Throttle]
sensitivity=1
axis=3
type=joystick

Now what you need to do is change the axis value from a 3 to a 4. Save out the file and then close it down. Now start the game and fly a mission. Hopefully you will now be able to speed up and slow down.

A number of customers using MS Precision Pro 2 joysticks have solved the throttle \ handling problems by having the throttle sensitivity bar set all the way to the far right (in game options). Then they set the joystick throttle at the midpoint before launching the actual game .
