Anonymous wrote:I'm sure it is here somewheres , and I have searched but how do I connect 2 computers together with RAS pro without being on-line. thanks


Hi,

Assuming you have no network at all, you'll need:

1. A network card for each PC
- most modern PCs already have a network card built-in, but if it doesn't, any "100 Base-T" (or faster) card will do.

2. A "Crossover" network cable. This should be of the "Ethernet" type, with a connector similar to that of a US phone socket. Make sure it's of the "Category 5e" variety or higher. Make sure it's long enough to connect your two computers. (Remember, you'll want to avoid stepping on it or getting it caught in doors, so you may need to tack it to walls, run it over windows and under carpeting, etc.)



First, if you've bought network cards, plug one into each PC. I can't go into too much detail about this as networking is a subject that could easily filll a book. It's usually a painless plug-and-play process though. (If you do have trouble, check out the myriad support sites for Windows.) Don't forget to turn File & Printer Sharing on for both PCs as this activates some background network services you'll need later on.

The next step is to connect the two computers together using the cable. This is why you need to ensure it's a "Crossover" cable as this type of cable avoids the need to buy a separate 'hub' or 'switch' box.

Now you need to set one of the PCs up as a 'server' (also known as a 'host'). Choose the faster of the two PCs for this as this computer will need to run both the server _and_ the game at the same time.

Go to the Start Menu, go to the Programs sub-menu, then Small Rockets, then the "RAS" submenu. Open the "Run RAS Server" program.

If you're running RAS Pro, the server's "IP Address" will be displayed within the server program, so make a note of this. RAS Pro will ask for this address when you ask it to join a multiplayer game.

If you're running the original RAS, rather than RAS Pro, you'll need to discover the IP Address for your PC. You can find this by going to the Start Menu, clicking "Run..." and typing cmd.exe into the box that pops up. Press Enter or Return on the keyboard and you should see a throwback to the 1970s appear on your screen, with something like this on it:

C:\Windows\>

Type this:

ipconfig /all

You'll see some technical gubbins appear in the window. (You may need to resize the window to read it all.) What you've just done is run a program called "IPCONFIG" and told it to display the configuration information for each network port on your computer. You should look for the "IP Address" or "Internet Address" entry for your network card. The address will look something like this:

192.168.0.2 (or 10.0.0.1 or a similar quartet of numbers.)

This is the IP Address you need to enter when RAS asks you for it. Both computers will need this address, so make a note of it.

Close the scary window as you don't need it any more.

Now run the RAS on each machine and start a network (or "LAN") game. Remember to type in that IP address when you're asked for it.


I think that about covers it. I'm typing this from memory, so my apologies if I've missed a step.

We also have a networking-specific support page here.
