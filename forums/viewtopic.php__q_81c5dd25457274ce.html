Q10244 - HOWTO: How can I configure my router?


We first recommend that you manually forward ports on your router to use GameSpy Arcade. Please see your router manufacturer's guide for this.

If you are having trouble, Port Magic is a tool that may help. NO guarantees.

If you've used a firewall or router before, you know how hard it can be to open ports for specific applications. Port Magic takes away this tedious task and makes it easy to open ports so that your programs and multiplayer games can "talk" on the Internet. It works with your Internet gateway, and is fully customizable, giving you complete control over the way programs communicate over your network. PortMagic is inherently more secure than manually opening and closing ports because it only opens the ports when needed.

Getting Started

You first need to download Port Magic and then install it. Once installed, reboot your computer and then run the program. You will have to go through the initial configuration which shouldn't take more than a couple of seconds. One of the configuration steps deals with the Do Not Disturb feature - select Allow all port requests. Any ports that are required to be opened when playing full-screen games shall now be automatically mapped.

Port Magic runs in your Windows System Tray. When a program tries to open a communicate with the Internet, Port Magic will ask if you want to allow the program to open the port. Clicking on "Yes" will automatically configure your gateway and will allow the application to access the Internet. Choosing "No" will leave the port closed. Note: In order for Port Magic to open ports, it must be running in your System Tray.



Fig. 1 : Notification prompts for applications


Using Port Magic is easy: simply keep the program running in your System Tray whenever you wish to play a game. If you have the 'Do Not Disturb' feature active and mapping ports, you do not need to worry about allowing Internet access to your applications and games!

Configuring Applications

Port Magic also allows you to configure individual applications' access rights to the Internet. Right-click on the Port Magic icon in your System Tray and select "Applications". A window that displays information about the programs that have requested to open ports will appear:



Fig. 2 : Applications Window


Information about the programs that have requested to open ports as well as the current ports in use is available. There is also an Action column which allows you to configure specifically how Port Magic handles requests:

Never Map denies all requests from that program
Prompt will display a notification popup each time an application requests a port to be opened (see Fig. 1)
On-Demand (recommended) opens and closes the ports automatically as they are requested by the application.
Leave Mapped creates a port rule on your gateway, thus leaving the port open at all times

Enabling 'Show Hidden' will display the applications that have been set to 'hidden' in the Application Properties window (see below.) Double-clicking on the Application Name will open another window that allows you to configure that application's port requests in depth:



Fig. 3 : Application Properties


Among other things, the currently Opened Ports and Recent Port history are displayed here. You have the option to Hide the Application from the list, as well as Monitoring all network interfaces. Note: By default, Port Magic only monitors the default interface (0.0.0.0). If a specific application is having connection problems or requires ports to be opened on another interface, enable this option.

General Options

The Options window lets you change your preferences for running Port Magic:



Fig. 4 : Configuring Options


We recommend you ENABLE the 'Always map ports without asking' option - this is the quickest and easiest way to play your games without always having to worry about granting access to specific programs. Notice that you also have the option to configure the Port Magic notifications.

If you are using a login name and password that are different that the default ones provided by your gateway, you must enter the information here as well so that Port Magic can access it.

Port Magic and Arcade

Using Port Magic to play your games on Arcade is very easy. We recommend you set the 'Do Not Disturb' mode in the Options to "Allow all port requests", OR that you enable the 'Always map ports without asking' option. This ensures that anytime a game is being launched and a port needs to be opened, Port Magic will take care of it. If you prefer having Port Magic close the ports when they are not in use for safety reasons, set the 'Action' of the application to "On-Demand" or "Prompt". Remember that Port Magic must be running in your System Tray (unless you use the option 'Leave Mapped' for your applications.)

PureNetworks has a great Support Forum if you have any specific inquiries or technical issues with using Port Magic.
