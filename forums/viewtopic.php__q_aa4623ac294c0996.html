Unfortunately both of these games were written before XP and they are not strictly compatible. As it turns out they are also hard to fix.

We will be updating some of our other games to make XP friendly, but unfortunatley we can't do much with these two.

You might try windows compatibility mode tho

Click the right mouse button over the games icon.
Select properties
Click the 'compatibility tab'
Check the 'Run this program in compatibility mode for' box
Select 'Windows 98' from the list
