bry wrote:
wheres the cmd.exe


[WINDOWS KEY] + [R] should bring up a little "Run..." box.

Type: CMD.EXE into that box and press [RETURN] or [ENTER].

The scary-looking window that appears is the command-line interpreter. If you can recall MS-DOS, or if you've ever used UNIX or VMS in anger, it'll feel similar.

You may need to navigate to the game's folder before you can run SRKEY, so use the cd command to do this. (The command's name comes from "change directory" -- a 'directory' was the old name for a folder, back in the pre-Windows days.) Note that you'll need to use quotation marks around folder names, file names and command names that have spaces in them -- cd "this is a folder". If you don't, CMD will get very, very confused.

E.g. if Red Ace Squadron is in the usual place on drive C:, you would type this:


C:
cd \
cd "Program Files"
cd "Small Rockets"
cd "Red Ace Squadron"


As you type each line, you should see the current folder path displayed to the left of the cursor as confirmation of where you are.

You can now run SRKEY by typing:

srkey -?

This should bring up the SRKEY 'help' screen, which will tell you what the option is for unlocking the game. (I'm in the middle of packing for my relocation, so I can't tell you what it is directly; my PC is already boxed up!)

Typing help will give you a list of built-in commands and programs. Most programs and commands also support the de-facto standard 'help me!' option, which is either command -? or command -h. Typing this should bring up a list of options and a brief intro to the program itself and how it's supposed to be used.
