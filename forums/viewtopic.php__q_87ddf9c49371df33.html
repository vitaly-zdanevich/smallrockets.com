TO SOLVE WINDOWS FIREWALL ISSUES ONLY

You must have Windows XP with the SP-2 update. If you have the Windows XP Firewall OFF and are using a different vendor's firewall product, you will need to check THEIR INFORMATION.

Now... this is what you do IN ORDER.

CLICK Start > Settings > Control Panel > Windows Firewall.

Click EXCEPTIONS

You will see a LIST of PROGRAMS that Windows XP Firewall is ALLOWING. Be SURE that THESE are on the LIST and are CHECKED.

1. Play Red Ace Squadron Pro

2. Start Red Ace Squadron Pro Server

3. Gamespy Arcade.

IF any of these are NOT SHOWN.... click ADD PROGRAM. Find the MISSING PROGRAM and either HIGHLIGHT and click OK or simply just DOUBLE CLICK the MISSING PROGRAM.

Now, be SURE that ALL THREE are in the EXCEPTIONS LIST and ALL THREE are CHECKED.

That's it!

GAMESPY PATH HELP

If you get an error message about PATH... do this. In RAS Lobby... click on GameSpy in UPPER LEFT. Then click OPTIONS. Go down to GAMES. On the GAMES LAYOUT, to the RIGHT, it should SHOW "Red Ace Squadron". If it DOESN'T, go BACK to GameSpy again and click SCAN FOR GAMES. It will HIGHLIGHT your local disk (C), then click SCAN NOW. Okay... now go back to GameSpy > Options > Games. Click on "Red Ace Squadron" to highlight. It will show you the PROGRAM LOCATION. Click BROWSE and then click THIS PROGRAM LINE "acenet_client_release". That's it... your PATH is SET. If you are still having problems... then be SURE that your Small Rockets Folder contains your download of Red Ace Squadron. You will know and can verify this in the Program Location information noted above. If all else fails... DELETE the entire Small Rockets FOLDER..... KILL EVERYTHING (including any ICONS left on your DESKTOP). REBOOT your computer. Now, REINSTALL a fresh copy of RAS (Pro). It is IMPORTANT that you insure the GameSpy path goes to your .exe file.

4. If you START a server which you have customized the way you want for the GameSpy RAS Lobby.... PLEASE be sure to put PRO somewhere in your server name so people with and without PRO know where they can play.

It is important that you understand... that someone CAN fiddle with their own settings (those that know how)... but the security and anti-cheat is they CAN'T ENTER a host server with CHANGED FILES. The HOST SERVER verifies ANYONE who tries to enter. IF their SETTINGS are CHANGED and DO NOT MATCH EXACTLY the HOST SERVER... they will NOT BE ALLOWED TO ENTER! Joystick configurations, Mouse configurations and Plane painting do NOT affect it. Only things messed with in the OBJECTS FILE. So, the HOST SERVER SETTINGS control the game and the players that play in your server.

You will notice that the program automatically puts TWO DESKTOP ICONS on your Desktop. One for the GAME and one for the SERVER. You can easily change your SET-UP and CHANGE your settings RIGHT FROM YOUR DESKTOP!

Okay, here is how to do it. Double Click on the Server Icon on your desktop to start up your server (be sure it is NOT MINIMIZED).

Then, go to the menu on the top window - you should see 'File' and 'Help'.

Click File - and you should see the menu. You need to CLICK disconnect to DISCONNECT the server to edit its settings. Now, go back to File>Preferences...

Now you can set your preferences in the windows box. When you are done you can reconnect the server - go to File>Connect and your options will be available to everybody. If you decide to go back to the DEFAULT SETTINGS there is a button there that will do it automatically for you.

There's a section on this in the minisite manual. (in minisite directory) - check out the server.htm document.

I highly recommend that you PRINT THIS OUT and have all these things to work with and refer to. Just REMEMBER that when you go into a HOST SERVER you are PLAYING by THEIR RULES, regardless of WHAT you may have SET on YOURS!

RADAR SETTINGS (In Server Set-Up)

ALWAYS - Regardless of whatever setting you make to the "Above Height" configuration, ALL PLANES will be VISIBLE.

ABOVE HEIGHT - (My Favorite) - You designate how HIGH all the planes MUST BE before they become VISIBLE. Spawn and Respawn (since they are UNDER the height) will be INVISIBLE.

ABOVE HEIGHT OR LANDED - This makes ANY landed plane (spawn, respawn or just sitting somewhere) VISIBLE! Once the plane starts to MOVE, the plane THEN becomes INVISIBLE until it goes above the "Above Height" setting.

NEVER - This setting completely DISABLES the RADAR. ALL PLANES will remain INVISIBLE for the ENTIRE GAME.

CLASSIC - Functions EXACTLY like the original game.
