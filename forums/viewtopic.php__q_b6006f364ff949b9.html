Jon rolls his own software. It's a genetic illness, apparently.

However, the guys at Unity Technologies — http://www.unity3d.com — make some good tools which may be a good fit for you if you want to make a game.

If you just want to make 3D models of planes, I suggest a modelling tool like 3DS Max, Maya, Milkshape, Blender (which is free but tricky to learn), or Cinema 4D. There are lots of others too, but as I'm not a professional 3D modeller myself, I don't know most of them. (I have the very cool Cheetah3D on my Mac for the odd icon and bit of graphic design work, but if you're using Windows, that's not much use to you.)

As for what's happening here: not a lot. Most of our games won't work on the latest versions of Windows, so Jon's working flat out rebuilding our existing games using a new engine of his own design. I'm working on the design for Red Ace Squadron 2. Jon posts progress reports to the forums, but I have to remind him to do so or he forgets.

In the meantime, the site is in sleep mode. It's just ticking over, with the occasional post here and there, but activity isn't likely to pick up until the updated (and new) games start trickling out.

Hi,

Yes, you can build planes (or any other model) in Blender.

As for how they could be added to RAS Pro: I don't think it's possible. It depends on which file format(s) the game supports for its 3D models and Blender didn't exist when the existing "Red Ace..." game engine was created way back in early 2001.

Jon does want to make it easier to create "mods" for our future games, including RAS 2, but the details are not yet confirmed. (For example, an "Airplane Factory" editing tool may be required to allow people to define the plane's in-game characteristics, including: gun types, firing speed, engine power, handling details, etc.)
