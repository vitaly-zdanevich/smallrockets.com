I think you're right about the meaning of "air7goal0" -- it sounds like "mission 7 first objective" to me. (It may be that there are multiple "goal0" entries, in which case these would be referring to all the items you have to take out to complete said goal.)

The best way to approach a project like this is to ask yourself what each mission needs to define. You'll need to specify which map you're going to use; what the objectives are; what any handicaps -- how many bombs, bullets and so on. -- might be; whether the mission is for Axis or Allied pilots, etc.

There's also the question of when / where the mission appears -- i.e. its location in the missions menu -- and which briefing text to use.

I would think that...

- Name is probably used to link to the briefing text.

- ID probably defines the map to use (and possibly whether it's an Axis, Allies -- or maybe both -- mission).

- Groups might be used to define where the mission appears in the missions menu;

Type seems to be objective-specific, in which case it probably tells the game engine what kind of objective it is: a factory, a hangar, a plane on a runway -- whatever. Targetid is probably just a number which is used to index the objectives when the game is running. (There may be multiple objectives, in which case there'd be IDs running from zero and up. Computers count from zero, not one, so a mission with five objectives would have them numbered 0-4.)

DISCLAIMER: I'm a Mac user these days and haven't played the RAS games in ages. My RSI means I'm not much good at action-heavy games anyway, so I prefer what the market now refers to as "casual" games.

The "up", "at" and "right" elements are used for orientation, similar in concept to pitch, roll and yaw, but using 3D graphics terminology.

Ordinancetype probably defines what weapons you're armed with. (I suspect you'd get a second set of "ordinancetype" and "numordinance" entries for missions where another type is also available but I'm guessing here.)

Numordinance would tell the game how much of the type of ordinance you get for this mission. In this case, 0 probably means 'infinite'.

You should also consider that there should also be something which links each mission to its mission briefing text. I think the "name" entry may be this link, so see if any other text files refer to the same name. Maybe they might give clues to the other entries too.

Finally, I suspect the pickups are also defined in these files somehow, so that may explain some of the type or ID numbers.

I wish I could give more useful answers, but I don't think you'll break anything by just fiddling with the files and experimenting. Just make sure you keep a backup of each file you change, so you can set it back afterwards.
