Below you'll find explanations for some of the industry jargon currently used.

STB (Set Top Box)
Set Top Boxes are playing an increasingly important role in the digital entertainment revolution. Initially developed as enabling devices for digital TV, their capabilities now encompass interactive gaming and broadband functionality, which will in turn allow Electronic Software Distribution (ESD). A good example is the new STB recently announced by Pace which can download and play Dreamcast games.

DRM (Digital Rights Management)
DRM technology is used to protect software from piracy and give users paths to access features of software in a controlled way. Digital products are very easy and effectively free to duplicate and fast to distribute - for example by the Internet.

ESD (Electronic software distribution)
ESD is a method of software distribution which does not require a physical item (such as a CD) to be moved. Software is transmitted to the users machine via a network entirely digitally, and stored on the users harddrive for fast access. ESD allows for people to access software immediately from the comfort of their own home. If the software is not free, typically software distributed by ESD requires a Digital Rights Management component to protect the software from piracy, and provide the user a simple way of purchasing the product.

Online multiplayer games
Online multiplayer games are games which players can directly play against one another via the use of the Internet.

Multiplayer games
Multiplayer games are games which allow more than one player to play at the same time. A multiplayer game can be played on a single machine (for example with the display being split for use by each player) or via more than one machine connected via a network. Multiplayer gaming is most often currently used with reference to games which can be played over the Internet (see online multiplayer games)

Online gaming
Online gaming is a fairly broad term, and relates to games which have some sort of online component. This might be that the game is available in a web browser and acessed from a server, it could be that a game is digitally distributed or that the game has an online multiplayer component.
