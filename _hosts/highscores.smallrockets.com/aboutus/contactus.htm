Support

If you have a support question about purchasing ESD games, please read our help page first.

If you have a technical support question for a game please make sure that you have read the games documentation fully first before contacting us. You can find this by clicking here, then click 'more info' for for the game you are having problems with and then click 'Support' for support details.

If you are having difficulty getting through a game, you might want to try a cheat.

You may find that your question has already been answered on our forums so its also worth checking there first, or perhaps posting your query or comments there so others can read them.

If you are still having problems you can email technical support at support@smallrockets.com.
