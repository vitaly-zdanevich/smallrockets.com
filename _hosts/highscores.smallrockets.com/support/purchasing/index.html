How do I purchase a game?

Purchasing a game from SmallRockets is secure, quick and easy:

  1. Download and install the game you're interested in. Make sure it works correctly on your system and try it out to see if you like it.
  2. Go to the shop and click 'buy it' on the game you want. This will add the game to your shopping basket.
  3. Click on 'checkout now' if you are happy with your basket's contents.
  4. If you don't have an account, type in your name and email. Your email must be valid as that is where your receipt and purchasing details will be sent. If you do have an account type in your email and password if you are asked for it.
  5. Enter your credit card details
  6. Confirm your purchase
  7. If your payment is accepted you will be emailed a receipt. Also you will now be on the account page which will show you your purchased licence code. On Windows systems you can click on this key to install it
  8. Once the key is installed, you can start the game and you will be able to access all of its features.

Note that you can never lose a game, as the game and the licence key you purchased will be kept on the website.

I've replaced my machine, how do I get the games back?

The process is pretty straightforward...

  1. Download and install the demo of the game you purchased. You can find all the current games and downloads in the shop section.
  2. Login to your account
  3. Install your licence codes (on windows do this by clicking on the licence code)

I've entered the licence code, but nothing happened?

If a licence code was successfully installed a box will appear saying 'The key has been successfully installed on this machine'. At this point when you start the game, on the main game page - the one where you select the major options - you should now see some text along the line of 'Full Version registered to: Your Name'. This shows that you now have the full version of the game. If the game says 'demo version' or 'not registered', then it does not have the licence key correctly installed.

Note that many of the games work during play by having levels 'cracked open'. The way this works is that you have to win on previous levels to access subsequent levels. This is a fairly common game play system that has been used on thousands of games - its useful because it provides progression through the game, and rewards the player for successfully winning.

What this means though is that even if you have just purchased the game you may not be able to access all the new levels - because you still have to win at previous levels.

How do SmallRockets games work?

All SmallRockets games are distributed electronically. That means you can obtain them by downloading them via the Internet, and you do not have to buy a physical copy of the game (such as a CD).

The game demos are completely free to download. When you download and install a game, it will run as a demo (or trial) version - a small selection of levels and features will be available to sample, so you can judge whether you'll find the full registered version interesting and exciting.

To play the full version, all you need to do is purchase a licence code. All the files the game requires are contained in the demo version you've already downloaded, so you don't need to download anything else. Once you have the licence code, the full version can be unlocked instantly!

Do I get a CD when I purchase a game?

No. SmallRockets sells games via 'ESD' (electronic software distribution). Doing so means that customers can try out games, and access full versions of games online immediately.

If you're worried about losing the game once you've bought it, rest assured that you will always be able to download any of the game demos from site, and you can always look up any licence codes from the account pages.

Can I buy your games in a store?

SmallRockets only publishes its games online. However we have done deals to sell some of the games via retail in some territories. You'll need to check at your local retailer.

I don't want to buy online. Are there alternatives?

You could try and check your local retailer to see if they stock our games - but basically you can only be sure of purchasing our games online.

I don't have a credit card. What next?

You require a credit/debit card to purchase our games online. We currently do not accept cheques or postal orders, and we do not have a telephone sales service.

How do I use my licence code?

On Windows based systems you can click on the licence code in the account screen. You need to be able to login to do this.

What should I do if I lose my licence code?

You can always get your licence codes back by logging in to the account page. It doesn't matter if you have lost your password, as long as you remember your email address, you can have a new password sent to you.

To get your codes go to the account page. It also gives you options to be sent a new password if you've forgotten yours.

Will I have to download the full version again?

No. All the files required by the game are contained in the demo version. You only need to unlock the game with a licence code.

I'm having problems downloading a game

Downloads are typically fastest if you use a server closest to your geographical location. Our servers can get very busy, so if your connection is slow try downloading at an off-peak time.

If the game refuses to install, it may be that your download was incomplete; in this case, you may need to download a new working version. You can check your download by looking at the size of the downloaded file and see if its the same size as the size listed on the download page.

If you are still having problems try to download the games only from SmallRockets servers as listed in the download page for each of the games.

If your connection keeps getting dropped and you are downloading over a modem, you can try installing software which can continue downloading from where it left off when the connection was dropped. Software such as www.getright.com can do this. You do not need to purchase a version for it to be able to download our software - the trial version will work fine.
