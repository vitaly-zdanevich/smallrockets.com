Licence codes

Top tip!

Not all licence codes are created equal!

All of the information here on licence codes are for codes that have been purchased ONLY from this site. If you did not purchase the game from this site, the information here will not work for you. You will need to return to the site where you originally purchased the game from and seek the appropriate information from there.

You can also tell if you have a SmallRockets licence code by how the code looks. A SmallRockets licence is in the format X-XXXX-XXXX-XXXX where X is either a letter or a digit. If your code has more of less than 13 letters/digits then it is not a SmallRockets code.

NOTE! That if you have problems setting your licence code, and you are sure you have purchased a SmallRockets code, then the problem may be you haven't downloaded a SmallRockets version of the game. In this case please download and install a version of the game from this site. Click 'Games' and select 'free downloads' and download from 'SmallRockets'.

Licences codes are used to gain access to full versions of SmallRockets games. You must have your game installed before you set a licence code.

You can set them automatically or manually. Once set you will be able to access the full features of a game. Setting a licence key automatically is by far the easiest way of doing things, and is therefore the recommened way to set your codes.

Top tip!

If you have problems setting your key try the latest SrKey program

If you downloaded your game a while ago, or from a site other than Small Rockets and you have problems setting your licence code, try downloading and installing the latest version of the SrKey program.

Automatically setting a licence

The most simple way to enter a licence code is using the automatic system. To do this you need to go to the account page on the website, and login. Once logged in, all of your licence codes will be listed. If you click on a licence code, you will get a box like below. Click on 'Open'.

The licence code should then install, and you will see box like below

Typing in a licence code

You must have your game already installed before you enter your licence code. You can use the list box below to bring up the licence code dialog box.

Top tip!

The 'Enter Licence Code' box doesn't appear?

On some systems it is better to click 'Save', select a location on your machine, and once the code has downloaded select 'Open'.

Manually setting a licence code

If you have a 'Set licence for xxxx' icon on your desktop click this, and a box will appear as below.

Otherwise go to

  1. Click the 'Start' button (typically in the bottem left corner of the screen)
  2. Click 'All Programs'
  3. Click 'SmallRockets'
  4. Click the name of the game you wish to unlock
  5. Click 'set the game licence'

Fill this box in with the information exactly as you have been given.
