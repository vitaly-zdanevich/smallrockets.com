System Specification

The following are the system specifications (requirements) for Small Rockets Backgammon:

  • Windows 95 / Windows 98
  • IBM PC compatible processor, Pentium 166MMX or higher
  • 16Mb RAM (32Mb RAM recommended)
  • 10MB Free hard disk space
  • PCI/AGP Windows compatible video card (1Mb minimum)
  • DirectX 7.0 or greater
  • Microsoft compatible Mouse
  • (Recommended) SoundBlaster or DirectSound compatible sound card

Comments

  • If any problems are encountered when using the 'Website' or 'Instructions' options from within the game, we recommend that you use the shortcuts from the START menu to access the Small Rockets website and the games Manual.
  • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers for the major video chipsets). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
  • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Backgammon is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
  • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
  • Windows 95 - Users with Windows 95 based systems may experience problems with their Windows desktop resizing to 640*480 if they minimize the game. If this problem is encountered, it can be solved by setting the Windows desktop colour mode to 16-bit colour.
    This can be done by right clicking on the Windows desktop and selecting 'Properties', from the 'Display Properties' menu that appears select the 'Settings' Tab and from here the colour mode can be changed. Alternatively, the problem can be avoided by not minimizing the game (either via ALT/TAB or by selecting to view the instructions/website from within the game).

Sound Cards

Small Rockets Backgammon should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

  • Aureal Vortex 2
  • Creative Labs AWE64
  • Creative Labs AWE64 PCI
  • Creative Labs Sound Blaster 128
  • Creative Labs Sound Blaster Live!
  • ESS ES1869
  • ESS Maestro I (Videologic Sonic Storm)
  • ESS Maestro II (Videologic Sonic Storm Pro)
