System Specification

The following are the system specifications (requirements) for Hot Chix 'n' Gear Stix:

  • Windows 95, Windows 98 & Windows ME
  • IBM PC compatible processor - Pentium II 233 or equivalent
  • 32Mb RAM
  • Supported 3D Accelerator Card (4Mb minimum)
  • 60MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • Hot Chix 'n' Gear Stix supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 1, 2, 3, 5, Rush, Banshee and Velocity
    • 3D Labs Permedia 2, and Permedia 3
    • Videologic PowerVR Neon 250
    • ATI Rage Pro Turbo AGP, Rage Pro Turbo PCI, Rage LT Pro, Rage128, Rage 128 Pro, Rage MAXX
    • Intel i740, Intel i810
    • Matrox G200, G400
    • Nvidia Riva 128, TNT, TNT2, Vanta, GeForce, Quadro, GeForce 2
    • Rendition Verite V2x00
    • S3 Savage 3D, Savage S4 and Savage2000

    Comments

    • The following video cards unfortunately do not meet the minimum requirements to play the game - Power VR PCX2, Matrox G100, Rendition Verite v1x00, SiS 6326, S3 Virge.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first.
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which drivers are currently being used, run DXDIAG (this can be done by selecting the RUN option on the START menu and typing DXDIAG) and select the Display tab. This will list the device name and driver version.
    • If stability problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that the game is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled 'Close Program'. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • ATI Rage Pro Turbo - If problems are encountered with the game when using the latest ATI drivers for video cards with this chipset, try using the default Windows 98 driver (ATI 3D Rage Pro (atir3) (5-11-1998) (4.10.1720)) or the original driver supplied with your card.
    • ATI Rage Pro Turbo and AMD Processors - Some AMD machines had problems running the game when using an ATI Rage Pro Turbo based video card and the latest ATI drivers. This problem could be avoided by using older ATI drivers.
    • ATI Rage LT Pro - Users with this video chipset may encounter problems with some text and textures within the game being blurred, there is currently no solution to the problem although it should not have a detrimental effect on gameplay.
    • Savage 3D - When running the game with an S3 Savage 3D video card using the latest S3 reference drivers, some graphical corruption was noted. If this occurs, try using the manufacturers drivers instead, as this was found to fix the problem (the Hercules Terminator Beast drivers were successfully tested).
    • Permedia 2 - We recommend that users of Permedia 2 based video cards run the game in 640*480, as this was found to give the best graphical results. Users may encounter problems with some text and textures within the game being blurred, but this should not a detrimental effect on gameplay.
    • Power VR PCXII - Users with Power VR PCXII accelerator cards in their machines may experience graphical corruption when running the game despite the fact that their primary video card is compatible. If this occurs disabling the Power VR cards acceleration (via the cards tab in the 'Display Properties' window) was found to solve the problem.
    • Nvidia Riva 128 - When using the latest drivers for video cards with this chipset, although the game would run the quality of some of the graphics was found to be slightly inferior to those displayed with older drivers.
    • Nvidia Riva TNT - Users with Nvidia Riva TNT cards are advised not to minimise the game or to select the option to go to the Website from the games Main menu. To access the website we recommend shutting down the game and using the shortcut created in the Chix folder on the START menu.
    • Matrox G400/G200 - If problems are encountered with icons of the desktop being moved after playing Chix, this can be solved by activating the option 'Automatically save/restore desktop icon positions' from the Matrox Powerdesk options menu. This can be found by right clicking on the desktop and selecting 'Properties', then selecting 'Settings', 'Advanced' and 'Options'.
    • Nvidia TNT/Vanta/TNT2/GeForce/Quadro/GeForce 2 AGP cards - When using drivers for any of these chipsets based on Detonator 3.53 or above, the game may fail to run, displaying a black screen upon starting. If this occurs, we have found that disabling the AGP support within DirectX will solve this. This can be done by running DXDIAG (use the RUN option on the Windows START menu and type ‘DXDIAG’). Once the DirectX Diagnostic Tool has opened, select the ‘Display’ tab and click on the icon next to ‘AGP Support’ to set it to Disable. Once this is done, Chix should run without any problems. N.B. We recommend that AGP support be enabled again once you finish playing Chix (otherwise speed problems may be encountered with other software), this can be done by following the steps outlined above to disable AGP support and toggling the ‘AGP Support’ option to ‘Enabled’.
    • Nvidia Riva TNT PCI - When using Nvidia Riva TNT based cards with Nvidia Detonator 3.53 drivers or above, screen flickering may be encountered during races. If this occurs, we recommend either setting the games detail level to LOW (which should solve the problem) or using older drivers (either manufacturers drivers or Detonator 2.08 drivers).
    • S3 Savage 4 - Using the latest S3 drivers for Savage 4 based cards (S3 Inc Savage 4 (Engineering Bitflip) (4-19-2000)(4.12.01.8215-8.20.18) users may find that some textures within the game, especially within tunnels may be mildly corrupted. Gameplay is not affected but users can fix this problem by using the latest manufacturers drivers instead. No problems were seen using the following drivers: Elsa Winner 2 (10-29-99) (4.11.01.0310-0002) & 3D Blaster Savage 4 (11-3-99) (4.11.01.2104)
    • Diamond Stealth 3 S540 - It was found that some graphics will be mildly corrupted when running the latest drivers with this card. Some of the track graphics will suffer slight graphical problems, generally where shadows are present and when the car is in tunnels. This corruption was seen with both the latest Diamond drivers and the latest S3 reference drivers. Currently no fix is known other than to user older drivers.
    • Videologic Power VR Neon 250 - When running this video card using recent drivers, the graphics during races may be corrupted. If this occurs, the problem can be solved by disabling the AGP support within DirectX. This can be done by running DXDIAG (use the RUN option on the Windows START menu and type ‘DXDIAG’). Once the DirectX Diagnostic Tool has opened, select the ‘Display’ tab and click on the icon next to ‘AGP Support’ to set it to Disable. Once this is done, Chix should run without any problems. N.B. We recommend that AGP support be enabled again once you finish playing Chix (otherwise speed problems may be encountered with other software), this can be done by following the steps outlined above to disable AGP support and toggling the ‘AGP Support’ option to ‘Enabled’.

    Sound Cards

    Hot Chix 'n' Gear Stix should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 2 (Diamond Monster Sound MX300)
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • Crystal Sound Fusion (Videologic Sonic Fury)
    • ESS ES1869
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)
    • Crystal SoundFusion (Videologic Sonic Fury)
    • Yamaha XG

    Comments

    • Crystal Sound Fusion - If any sound corruption is encountered with this card, it can be solved by changing the Hardware Sound Acceleration Level from 'Full acceleration' to 'Basic acceleration'. This can be done via DXDIAG, simply run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Sound’ tab. From this menu the 'Hardware Sound Acceleration Level' can be set.

Joysticks/Gamepads

Hot Chix should work with any DirectInput compatible controller, it has been tested and found to work with the following products:

  • CH Products - Gamestick 3D, F-16 Combat Stick
  • Gravis - Blackhawk Digital, Xterminator Dual Control, Xterminator, Xterminator Digital, Gamepad Pro, Gamepad Pro USB
  • Interact - Cyclone 3D, Magnum 6, Makopad PC
  • Logic 3 - PC Avenger
  • Logitech - Wingman Extreme Digital, Wingman, Thunderpad Digital
  • Microsoft - Forcefeedback Pro, Precision Pro, Dual Strike, Sidewinder Pro, Freestyle Pro, Sidewinder Gamepad
  • Saitek - P550, Cyborg 3D USB, P2000
  • Thrustmaster - Top Gun USB, Fusion

Input Devices
  • No problems were seen during testing with standard joysticks, gamepads and mice. In order for Chix to work correctly with USB controllers (eg. Microsoft Sidewinder Pro, Microsoft Dual Strike), DirectX 7a or above must be present on the machine (see the DirectX page for more information and links to download the latest DirectX).
  • The default button setup for Hot Chix assigns button 0 to accelerate, button 1 to brake and button 2 to handbrake. Users can alter this default setting by opening the 'controls.ini' file in the directory where Hot Chix was installed. The button numbers can then be altered to settings that suit the user and the file then saved. Note that the button assignments for any given joystick/gamepad can be seen by opening the 'Joysticks' page within Windows Control Panel.

Steering Controls

Hot Chix should work with any DirectInput compatible wheel, it has been tested and found to work with the following products

  • CH Products - EXL500
  • Interact - FX Racing Wheelpad, Ultraracer PC, V3
  • Microsoft - Force Feedback Wheel
  • Saitek - R4 Racing Wheel
  • SC&T - Ultimate Per4mer
  • Thrustmaster - Nascar Supersport, Sprint Wheel

Steering Devices
  • No problems were seen during testing with standard wheels. In order for Chix to work correctly with USB controllers (eg. Microsoft Sidewinder Pro, Microsoft Dual Strike), DirectX 7a or above must be present on the machine (see the DirectX page for more information and links to download the latest DirectX).
  • During testing with the Saitek R4 racing wheel it was found that the best control performance was obtained by setting the wheel to 'Mode 3: Combined Analog'.
