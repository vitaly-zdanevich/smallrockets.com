General Comments

  • Tower of the ancients is not compatible with Matrox G100, Verite V1000 or PowerVR PCX2
  • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first
  • ATI Rage Pro – During testing, the graphical quality of the game was found to be superior if the latest ATI drivers were used rather than the default Windows 98 drivers for video cards with this chipset. We therefore recommend the latest ATI drivers be used when running Tower of the Ancients. Additionally, users are advised to change the game resolution from the Resolution Menu that appears upon startup rather than use the option to change resolution during the game.
  • ATI Rage Pro PCI – Some graphical problems may be encountered with PCI video cards using the ATI Rage Pro chipset. Please note that these problems are merely cosmetic and the game itself can be played without any other problems.
  • ATI Rage 128 – Users of ATI Rage 128 based video cards are advised to exit the game before changing the games resolution.
  • Permedia 2 – Some minor graphical problems were noted with transparencies in the game when using video cards with this chipset. These are caused by limitations of the video card and were found to have no effect on gameplay.
  • Diamond FireGL 1000 Pro – Users with this video card are advised to use the latest Permedia 2 reference drivers (listed below) rather than Diamonds drivers for the card.
  • Nvidia Riva Vanta – Users of Nvidia Riva Vanta based video cards are advised not to run Tower in resolutions higher than 1024*768.
  • STB Velocity 128 users - This game is incompatible with the latest Nvidia reference drivers. We recommend that you use the latest STB drivers (STB Velocity 128 (6-1-98) (4.10.01.0182)).
  • Diamond Viper V330 users - Under Windows 95 the game is playable with Diamonds Viper 330 drivers (Diamond Viper 330 (6-25-1999)(4.10.01.0127)).
  • Under Windows 98, V330 users are advised to use the Nvidia reference drivers (Nvidia Riva 128/128ZX (3-2-99) (4.11.01.0337)).
  • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible guarantee a games compatibility with them all. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
  • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which drivers are currently being used, run DXDIAG (this can be done by selecting the RUN option on the START menu and typing DXDIAG) and select the Display tab. This will list the device name and driver version.
