System Specification

The following are the system specifications (requirements) for Jetboat Superchamps:

  • Windows 95 / Windows 98 / Windows ME
  • IBM PC compatible processor - Pentium II 233Mhz or equivalent
  • 32MB RAM
  • Supported 3D Accelerator Card (4Mb minimum)
  • 65MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • Jetboat Superchamps supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 1, Voodoo 2, Voodoo 3, Voodoo Rush, Voodoo Banshee, Velocity 100, Voodoo 5
    • 3D Labs Permedia 2, Permedia 3
    • ATI Rage Pro Turbo AGP, Rage Pro PCI, Rage LT Pro, Rage 128, Rage 128 Pro, Rage MAXX
    • Intel i740, i810
    • Matrox G200 and G400
    • Nvidia Riva 128, TNT, TNT2, Vanta, GeForce, Quadro, GeForce, GeForce 2
    • Rendition Verite V2x00
    • S3 Savage 3D, Savage S4, Savage2000
    • Videologic Neon 250

    Comments

    • Jetboat Superchamps is not compatible with the following video chipsets - Power VR PCX2, Matrox G100, Rendition Verite V1000, SiS 6326, S3 Virge.
    • Users are advised to refrain from minimising the game or switching to other applications using ALT-TAB while a race is in progress
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which drivers are currently being used, run DXDIAG (this can be done by selecting the RUN option on the START menu and typing DXDIAG) and select the Display tab. This will list the device name and driver version.
    • If any stability problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Jetboat Superchamps is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled 'Close Program'. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • Power VR PCX2 - Users with Power VR PCX2 accelerator cards in their machines may experience graphical corruption when running the game despite the fact that their primary video card is compatible. If this occurs disabling the Power VR cards acceleration (via the cards tab in the 'Display Properties' window) was found to solve the problem.
    • ATI Rage Pro Turbo - Users are advised not to use the Windows 98 default drivers. The graphical quality of the game was found to be superior using ATI's own drivers.
    • ATI Rage Pro Turbo - Some problems were encountered when running the game on AMD machines with the latest ATI drivers (Rage Pro Turbo (5-21-1999) (4.11.01.2560)). In this situation we recommend using older versions of ATI's drivers.
    • ATI Rage LT Pro - If any problems are encountered when trying to start races, we recommend that you try setting the games detail level to medium or low.
    • ATI Rage 128/128 Pro - When using the latest drivers for these video cards, some minor flickering may be encountered on the speedometer during races. Unfortunately there is no solution for this problem at present.
    • Nvidia Riva 128 - During testing it was found that the best graphical quality was obtained when using the manufacturers drivers for Riva 128 based cards rather than the Nvidia reference drivers. Examples of the drivers are listed in the Recommended Video Drivers.
    • Nvidia Vanta - Graphical problems were encountered when using Nvidia Vanta cards and machines with Ali AladdinV motherboards. The problems were caused by having the latest Ali AGP driver present on the machine, if the AGP driver is removed Jetboats should run without any problems N.B. Please consult your motherboard documentation before removing any drivers
    • Nvidia Riva TNT / Vanta / TNT2 / GeForce / Quadro / GeForce2 - When running the game on machines with any of these chipsets and drivers based on Detonator 3.68 or above, problems may be encountered with Urban mist (missing graphics) and the Shrine track (game returns to desktop). If this problem is encountered, it can be solved by setting the Windows desktop to 640*480 in 16-bit colour mode (and restarting the machine after doing so). Once this is done, Jetboats should run in 640*480 resolution without any problems (please note it will not run in any other resolutions).
    • Matrox Millennium and 3DFX Voodoo 2 - Jetboats may fail to run on machines with a combination of a Matrox Millennium primary video cards and a 3DFX Voodoo 2 secondary adapter. If this occurs, it can be solved by reducing the Matrox Millenniums Acceleration. This can be done by Right clicking on the Windows desktop and selecting 'Properties', from the Display Properties menu, select the 'Settings' tab then click on 'Advanced'. Next click on the 'Performance' tab of the menu that opens and change the Hardware acceleration slider from Full to Basic. Click OK to close the windows and the machine will restart, Jetboats should now run without any problems.
    • S3 Savage 4 - When using the latest S3 Reference drivers (S3 Inc Savage 4 (engineering Bitflip (4-19-2000) (4.12.01.8215)), graphical problems may be encountered during races. If this occurs it can be solved by using the latest manufacturers drivers for your card instead (eg. (Elsa Winner II (10-29-1999) (4.11.01.0310)) or (3D Balster Savage 4 (11-3-1999) (4.11.01.2104))).
    • 3DFX Velocity 100 - Users with Velocity 100 video cards are advised not to run the game in a resolution of 1280*1024 as graphical problems may be encountered. All other resolutions will function without any problems.

    Sound Cards

    Jetboat Superchamps should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1 (Terratec Promedia Xlerate)
    • Aureal Vortex 2 (Diamond Monster Sound MX300)
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • Crystal SoundFusion (Videologic Sonic Fury)
    • ESS ES1869
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)
    • Yamaha XG

    Comments

    • Diamond MX300 users should use Aureal drivers rather than Diamond's latest drivers for this card. Sound was found to cut out in some circumstances using Diamond drivers.
    • Users with Videologic Sonic Storm Pro, Videologic Sonic Fury and Yamaha 192XG sound cards are advised to run the game with only basic audio acceleration. Failure to do so was found to result in the failure of some races (Urban Mist and Shrine) to function correctly.
      In order to change the audio settings, you will require DirectX 7 or higher on the machine. Run DXDIAG (this can be done by using the 'Run' command on the START menu and typing DXDIAG) and click on the 'Sound' tab once the DirectX Diagnosic Tool window opens, next change the 'Hardware Sound Acceleration Level' from 'Full Acceleration' to 'Basic Acceleration'.

Joysticks/Gamepads

Jetboats can be controlled using any Windows compatible joystick/gamepad with at least 4 buttons. The control buttons cannot be altered within the game. If you wish to alter the functions of the buttons you will need to either alter their settings within Windows (please consult your controllers documentation for details) or edit the file CONTROLS.INI. The CONTROLS.INI file can be found in the root of the Jetboat installation folder, and allows users to assign buttons to the various controls.

USB Controllers - When using USB controllers (eg. Microsoft Sidewinder Gamepad Pro) we recommend that users install DirectX 7.0a or higher on their machine. This revision of DirectX includes better support for input devices, and without it USB controllers may fail to work with the game. Please see the DirectX section for more information and links to download sites.

Jetboat Superchamps should work with any DirectInput compatible controller, it has been tested and found to work with the following products

  • CH Products - Gamestick 3D, F16 Combat Stick
  • Gravis - Xterminator, Gamepad Pro, Xterminator Dual Control, Blackhawk
  • Interact - Makopad, Magnum 6, Cyclone 3D
  • Logitech - Wingman, Thunderpad, Wingman Extreme
  • Logic 3 - PC Avenger
  • Microsoft - Sidewinder ForceFeedback Pro, Dual Strike, Sidewinder Gamepad, Sidewinder Gamepad Pro, Sidewinder Freestyle Pro, Sidewinder Precision Pro
  • Saitek - Cyborg 3D, P2000, P550
  • Thrustmaster - Fusion, Topgun

Input Devices
  • No Problems were seen when testing the game with standard joysticks and gamepads. With USB controllers (eg. Microsoft Sidewinder Pro, Microsoft Dual Strike) DirectX 7a or above must be installed on the machine (more information and links to download the latest version can be found on the DirectX page).
  • Microsoft Sidewinder Dual Strike - If any problems are encountered when running the game on machines with this controller, we recommend that users select the 'Joystick' setting on the controllers properties menu (see the controllers documentation for details on how to change this setting).

Steering Controls

Jetboat Superchamps has been tested and found to be compatible with a variety of steering devices (including USB peripherals).

The game can be configured to use steering devices by going to the 'Options' menu within the game and selecting 'Wheel' in the controls menu.

  • Please Note - DirectX 7.0a or above may need to be installed on your system in order for USB devices to be recognised by the game. See the DirectX page for more details and links to download the latest version of DirectX.

The following steering devices have been tested successfully with Jetboat Superchamps

  • Microsoft Sidewinder Force Feedback Steering Wheel & Pedals
  • Thrustmaster Sprint Steering Wheel & Pedals
  • Thrustmaster Nascar Super Sport Steering Wheel & Pedals
  • SC&T Ultimate Per4mer Steering Wheel & Pedals
  • Interact V3 Racing Wheel & Pedals
  • Interact FX Racing Wheelpad
  • Interact Ultraracer PC Wheelpad
  • CH Products EXL500 Racing Wheel & Pedals
  • Saitek R4 Racing Wheel & Pedals

Steering Devices
  • The game supports no Force Feedback interaction, hence there is no particular benefit in using the Force Feedback function found on some of these devices.
  • Saitek R4 Racing Wheel - During testing, the best control with this steering device in Jetboats was found to be obtained by setting it to 'Mode 3: Combined Analog'.
