System Specification

The following are the system specifications (requirements) for MAD : Global Thermonuclear Warfare:

  • Windows 95 / Windows 98 / Windows ME
  • IBM PC compatible processor - Intel Pentium II 233Mhz or equivalent AMD
  • 32MB RAM (64Mb or above Recommended)
  • Supported 3D Accelerator Card (4Mb minimum)
  • 50MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • DirectX 7 or higher
  • MAD : Global Thermonuclear Warfare supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 2, 3, 5, Banshee
    • 3D Labs Permedia 2 and Permedia 3
    • ATI Rage Pro Turbo AGP, Rage Pro PCI, Rage LT Pro, Rage 128, Radeon
    • Intel i740
    • Matrox G200 and G400
    • Nvidia Riva 128, TNT, TNT2, Vanta, GeForce 256 and GeForce 2
    • Rendition Verite V2x00
    • S3 Savage 3D, Savage S4, Savage 2000
    • Power VR Kyro

    Comments

    • This game is incompatible with 3DFX Voodoo1, Power VR PCX2 and PowerVR Neon 250 cards
    • Cyrix M2 - Unfortunately Cyrix M2 processors are not powerful enough to run the game. Only Intel and AMD processors are supported.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
    • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that MAD : Global Thermonuclear Warfare is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • Matrox Millennium G400 - Users with this video card are advised not to minimise the game. If access to the Windows desktop is needed we recommend closing the game down.
    • Savage 3D -If any problems are encountered when running the game with an S3 Savage 3D video card using the latest manufacturers drivers (we have tested with a Hercules Terminator Beast card and drivers), we recommend using the latest S3 reference drivers instead.
    • Savage 4 - If any problems are encountered when running the game with a Savage 4 based card using the latest reference drivers (we have tested with an Elsa Winner 2) we recommend trying the latest manufacturer's drivers.

    Sound Cards

    MAD : Global Thermonuclear Warfare should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1
    • Aureal Vortex 2
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)
    • Crystal Sound Fusion (Videologic Sonic Fury)
    • Yamaha XG

    Comments

    • Users should ensure that they have DirectX 7 or above installed on their system. Earlier versions of DirectX (eg. DirectX 6.1) will run the game, but music may be missing from some levels.
    • Sound problems (eg. crackling audio, pausing of gameplay when sound effects play) may be encountered on systems with 32MB RAM. Increasing the system memory (ie. to 64MB or above) should improve the sound quality.
