System Specification

The following are the system specifications (requirements) for NFK Santa's Gone Postal:

  • Windows 95 / Windows 98
  • IBM PC compatible processor - Pentium 166Mhz minimum, Pentium II 233Mhz recommended
  • 16MB RAM (32MB RAM recommended)
  • Supported 3D Accelerator Card (4Mb minimum)
  • 65MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • NFK Santa's Gone Postal supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 1, 2, 3, Rush, Banshee and Velocity 100/200
    • 3D Labs Permedia 2 and Permedia 3
    • ATI Rage Pro Turbo AGP, Rage Pro PCI, Rage LT Pro, Rage 128, Rage 128 Pro and Rage Fury MAXX
    • Intel i740 and Intel i810
    • Matrox G200 and G400
    • Nvidia Riva 128, TNT, TNT2, Vanta, GeForce 256, Quadro and GeForce 2
    • Rendition Verite V2x00
    • S3 Savage 3D, Savage S4 and Savage 2000

    Comments

    • This game is incompatible with Matrox G100, Power VR PCX2, PowerVR Neon 250, Rendition Verite v1x00, SiS 6326 and S3 Virge cards.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first
    • If any problems are encountered when using the 'Visit the Website' or 'Purchase the Game' options from the games pause menu, we recommend that you use the shortcuts from the START menu to access the Small Rockets website or get the full version of the game
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which drivers are currently being used, run DXDIAG (this can be done by selecting the RUN option on the START menu and typing DXDIAG) and select the Display tab. This will list the device name and driver version.
    • Before starting Santa's Gone Postal, you are advised to close down all other programs that may be running. Doing this will ensure that Santa's Gone Postal is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • ATI Rage LT Pro - Problems with in-game text may be encountered if the game is shut down and immediately re-started. Should this occur we recommend re-starting Windows.
    • ATI Rage Fury MAXX - The drivers supplied with this video card (Rage Fury MAXX (1-5-2000)(4.11.01.7925)) will not run Santa's Gone Postal. The problem can be solved by obtaining the latest Special Purpose drivers from ATI (see below for the driver we recommend). Although the game will run using the latest drivers users may experience some flickering of the screen during loading. The driver can be obtained from ATI's Special Purpose Drivers Page.
    • Permedia 2 - Users with graphics cards based upon the Permedia 2 chipset may experience minor problems with water effects in game. This is a deficiency on the part of the card and unfortunately cannot be fixed at this time. Gameplay will not be effected.
    • Permedia 3 - Users with Permedia 3 based graphics cards are advised not to use alt/tab or other key combinations to return to the Windows desktop. It may not be possible to alt/tab back into the game. To avoid this problem please close down the program to gain access to the Windows desktop.
    • Savage 3D -If any problems are encountered when running the game with an S3 Savage 3D video card using the latest manufacturers drivers (we have tested with a Hercules Terminator Beast card and drivers), we recommend using the latest S3 reference drivers instead.
    • Savage 4 - If any problems are encountered when running the game with a Savage 4 based card using the latest reference drivers (we have tested with an Elsa Winner 2 and a Creative Blaster Savage 4) we recommend trying the latest manufacturer's drivers.

    Sound Cards

    NFK: Santa's gone postal should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1 (Terratec Promedia Xlerate)
    • Aureal Vortex 2 (Diamond Monster Sound MX300)
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • ESS ES1869
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)

    Comments

    • Aureal Vortex 2 - Users may experience crashes as soon as the game is launched. If this occurs it has been found that disabling Direct Sound audio acceleration via the Vortex control panel will allow the game to be run with no problems.
