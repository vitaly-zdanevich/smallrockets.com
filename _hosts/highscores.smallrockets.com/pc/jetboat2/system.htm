    Comments

    • Jetboat Superchamps 2 is currently not compatible with ATI Rage Pro AGP, 3DFX Voodoo 1, Nvidia Riva 128, 3DFX Voodoo Rush, Rendition Verite v2x00, Power VR PCX2, Matrox G100, SiS 6326 or Rendition Verite V1000 chipsets
    • Cyrix M2 - Unfortunately Cyrix M2 processors are not powerful enough to run the game. Only Intel and AMD processors are supported.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first.
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
    • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Jetboat Superchamps 2 is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • 3dfx Velocity 100 - The game will not run in resolutions above 800*600 with this video card.
    • 3dfx Voodoo Banshee - Currently Jetboat Superchamps 2 will only support resolutions of up to and including 800*600 when running on systems equiped with Voodoo Banshee based cards.
    • 3dfx Voodoo 5 - Currently Jetboat Superchamps 2 will only support resoltutions up to and including 800*600 when running on systems equiped with Voodoo 5 based video cards.
    • ATI Rage Pro PCI - The game will not run in resolutions above 800*600 with this video card.
    • ATI Rage Pro PCI and Low Spec Machines - If any problems are encountered with the game crashing on low end systems with ATI Rage Pro PCI video cards, they can be solved by using the latest drivers from ATI (version (4.12.01.2632)). The drivers can be obtained from http://www.atitech.ca/na/pages/spdrivers/drivers.html Please note however that these drivers are unsupported by ATI at this time.
    • ATI Rage Pro and AMD K6 Systems - Users may experience some problems running Jetboats Superchamps 2 when using the latest ATI release drivers (4.11.01.2560) with AMD K6 based systems. Should this be the case we suggest that users try the latest beta drivers available from ATI (version (4.11.01.2623) or (4.12.01.2632)). The drivers can be obtained from http://www.atitech.ca/na/pages/spdrivers/drivers.html Please note however that these drivers are unsupported by ATI at this time.
    • Matrox Millennium G400 - Users with this video card are advised not to minimise the game. If access to the Windows desktop is needed we recommend closing the game down.
    • Matrox Millennium G400 - If any problems are encountered with corrupt textures when using the latest drivers (Matrox Millennium G400 (11-2-2000) (4.12.01.1700)) they can be solved by using older drivers (eg. Matrox Millennium (8-26-2000) (4.12.01.1640)).
    • Matrox Millenium G400 - Currently Jetboat Superchamps 2 is incompatible with Matrox Millenium G400 cards when running Windows 95
    • Neon 250 - Due to driver problems, the game may suffer from graphical corruption when run with Neon 250 video cards using the Driver Release v3.2.1.2 (Neon 250 - AGP 32Mb (11-3-1999) (4.11.01.10079)). We recommend using an older release of the card's drivers (see below for our recommended driver).
    • S3 Savage 3D - Users may encounter some minor graphical corruption on some textures within the game. Unfortunately there is no fix for this issue at present.
    • S3 Savage 4 - Some minor problems with textures were encountered when using the S3 reference drivers. These can typically be solved by using the manufacturer's driver instead.

Joysticks/Gamepads

Jetboat Superchamps 2 can be controlled using any Windows compatible joystick/gamepad with at least 4 buttons. The control buttons cannot be altered within the game. If you wish to alter the functions of the buttons you will need to alter their settings within Windows (please consult your controller's documentation for details). The default button configuration is Button 1=Accelerate, Button 2=Brake and Button 3=Turbo Boost.

USB Controllers - When using USB controllers (eg. Microsoft Sidewinder Gamepad Pro) we recommend that users install DirectX 7.0a or higher on their machine. This revision of DirectX includes better support for input devices, and without it USB controllers may fail to work with the game. Please see the DirectX section for more information and links to download sites.

Jetboat Superchamps 2 should work with any DirectInput compatible controller, it has been tested and found to work with the following products

  • CH Products - Gamestick 3D
  • Gravis - Xterminator, Xterminator Digital, Gamepad, Gamepad Pro, Xterminator Dual Control, Blackhawk Digital
  • Interact - Makopad, Magnum 6, Cyclone 3D
  • Logitech - Wingman, Thunderpad Digital, Wingman Extreme Digital
  • Logic 3 - PC Avenger
  • Microsoft - Sidewinder ForceFeedback Pro, Dual Strike, Sidewinder Gamepad, Sidewinder Gamepad Pro, Sidewinder Freestyle Pro, Sidewinder Precision Pro, Forcefeedback 2, Precision Pro 2, Sidewinder Joystick
  • Saitek - Cyborg 3D, P2000, P550
  • Thrustmaster - Fusion, Topgun

Input Devices
  • No Problems were seen when testing the game with standard joysticks and gamepads. With USB controllers DirectX 7a or above must be installed on the machine (more information and links to download the latest version can be found on the DirectX page).
  • Microsoft Sidewinder Dual Strike - If any problems are encountered when running the game on machines with this controller, we recommend that users select the 'Joystick' setting on the controllers properties menu (see the controller's documentation for details on how to change this setting).
  • Saitek Sp550 - We recommend that users with this controller play the game with it in a gamepad configuration rather than a joystick configuration to allow multiple button presses.

Steering Controls

Jetboat Superchamps 2 has been tested and found to be compatible with a variety of steering devices (including USB peripherals).

The game can be configured to use steering devices by going to the 'Options' menu within the game and selecting 'Wheel' in the controls menu.

  • Please Note - DirectX 7.0a or above may need to be installed on your system in order for USB devices to be recognised by the game. See the DirectX page for more details and links to download the latest version of DirectX.

The following steering devices have been tested successfully with Jetboat Superchamps 2

  • Microsoft Sidewinder Force Feedback Steering Wheel & Pedals
  • Thrustmaster Sprint Steering Wheel & Pedals
  • Thrustmaster Nascar Super Sport Steering Wheel & Pedals
  • SC&T Ultimate Per4mer Steering Wheel & Pedals
  • Interact V3 Racing Wheel & Pedals
  • Interact FX Racing Wheelpad
  • Interact Ultraracer PC Wheelpad
  • Saitek R4 Racing Wheel & Pedals

Steering Devices
  • The game supports no Force Feedback interaction, hence there is no particular benefit in using the Force Feedback function found on some of these devices.
  • Saitek R4 Racing Wheel - During testing, the best control with this steering device in Jetboat Superchamps 2 was found to be obtained by setting it to 'Mode 3: Combined Analog'.
