System Specification

The following are the system specifications (requirements) for Art Is Dead:

  • Windows 95 / Windows 98 / Windows ME
  • IBM PC compatible processor - Intel Pentium II 233Mhz or equivalent AMD
  • 32MB RAM (64Mb Recommended)
  • Supported 3D Accelerator Card (4Mb minimum)
  • 100MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • DirectX 7 or higher
  • Art Is Dead supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 2, Voodoo 3, Voodoo 5, Voodoo Banshee, Velocity 100
    • 3D Labs Permedia 2 (AGP only), Permedia 3
    • ATI Rage Pro Turbo (AGP only), Rage LT Pro, Rage 128, Rage 128 Pro, Rage MAXX, Radeon
    • Intel i740, i810
    • Matrox G200, G400
    • Nvidia Riva 128 (AGP only), TNT, TNT2 (all variations), GeForce, Quadro, GeForce2
    • S3 Savage 3D, Savage S4, Savage2000
    • Videologic Neon 250

    Comments

    • The following video chipsets are insufficient to run Art Is Dead - 3DFX Voodoo 1, 3DFX Voodoo Rush, ATI Rage Pro Turbo (PCI only), Power VR PCX2, Matrox G100, Rendition Verite V1000, 3D Labs Permedia 2 (PCI only), Nvidia Riva 128 (PCI only) and Rendition Verite 2200
    • Cyrix M2 - Unfortunately Cyrix M2 processors are not powerful enough to run the game. Only Intel and AMD processors are supported.
    • Users of systems with 32Mb of RAM may find that the game takes a long time to install. This is normal and is due to the number of game files installed and the level of compression used.
    • Some users may experience stability problems with Art Is Dead when it is installed into a directory with a long path name. Should this situation occur we recommend un-installing the game and re-installing to a directory with a shorter path or the default directory.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first.
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
    • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Art Is Dead is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • Accelerator cards - Users should be aware that Art is Dead will automatically choose an add-in accelerator card (ie. Voodoo2) should one be present in the users system.
    • 3DFX cards - Users with any 3DFX video card (Voodoo 2, Banshee, Voodoo 3, Velocity, Voodoo 5) may encounter minor graphical corruption when navigating the mansion. The corruption takes the form of thin black lines surrounding the paintings and doorways within the mansion. The problem only occurs on the navigation screens, the games contained in the pictures are not affected. Unfortunately there is no fix for this problem at present.
    • 3D Labs Permedia 2 (AGP) - Users with cards based on this chipset may encounter minor graphical corruption around paintings and doorways when on screens displaying the various rooms of the mansion. This will not affect the games contained in the paintings. Unfortunately there is no fix for this problem at present."
    • ATI Rage LT Pro - Users of Rage LT Pro based cards may experience some problems with corruption of the mouse cursor when placed at the top of the screen. The problem is cosmetic only and will not affect gameplay.
    • ATI Rage Pro AGP - If any problems are encountered with minor graphical corruption on systems with ATI Rage Pro AGP video cards, they can be solved by using the latest drivers from ATI (version (4.12.01.2632) or above). The drivers can be obtained from http://www.atitech.ca/na/pages/spdrivers/drivers.html Please note however that these drivers are unsupported by ATI at this time.
    • ATI Rage Pro Turbo AGP - Should users experience problems getting Art is Dead to run on systems fitted with cards based around the Rage Pro AGP chipset, we recommend reducing the colour depth and resolution of the Windows desktop. With Windows set in a high resolution and colour depth mode, Art is Dead may not be able to access enough memory on the video card to start correctly. Reducing the demand on the card by reducing colour depth and/or resolution will allow the game to start correctly.
    • Diamond Viper v330 - Users with this video card are advised to use the Nvidia Riva 128 Reference drivers (see below for driver details) as the game may fail to start with Diamonds own drivers.
    • STB Velocity 128 - Users of STB Velocity 128 (Nvidia Riva 128 based cards cards) may experience graphical corruption when playing Art is Dead when using Nvidia reference drivers. Should problems be encountered we recommend that users try the latest STB drivers for the card.
    • Nvidia Riva 128 - Should users experience problems getting Art is Dead to run on systems fitted with cards based around the Nvidia Riva 128 chipset we recommend reducing the colour depth and resolution of the Windows desktop. With Windows set in a high resolution and colour depth mode, Art is Dead may not be able to access enough memory on the video card to start correctly. Reducing the demand on the card by reducing colour depth and/or resolution should allow the game to start correctly.
    • Nvidia Riva 128 - Users with cards based on this chipset may encounter minor graphical corruption around paintings and doorways when on screens displaying the various rooms of the mansion. Unfortunately there is no fix for this problem at present."
    • Matrox Millennium G400 - Users with this video card are advised not to minimize the game. If access to the Windows desktop is needed we recommend closing the game down.
    • Neon 250 - Users with this video card are advised not to minimize the game. If access to the Windows desktop is needed we recommend closing the game down.
    • Savage 3D - Should users of cards based upon this chipset experience problems with flickering in-game graphics, we recommend that they use the latest manufacturers drivers instead of the S3 reference drivers (see below for our recommended driver).
    • Savage 2000 - Users of cards based upon the S3 Savage 2000 chipset may experience some corruption of text within the game. The corruption is fairly minor and will not affect gameplay.

    Sound Cards

    Art Is Dead should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1
    • Aureal Vortex 2
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)
    • Crystal Sound Fusion (Videologic Sonic Fury)
    • Yamaha XG

    Comments

    • Users should ensure that they have DirectX 7 or above installed on their system. Earlier versions of DirectX (eg. DirectX 6.1) will run the game, but music may be missing from some levels.
