Description

They’ve been playing it for 500 years - but you can start today

Backgammon is a classic board game that has been played in one form or another since the 1500s. The basics of the game are simple to learn: each player has a number of counters placed on a distinctive black and red board, the objective being to return all counters safely to the player's home area. However, at any point counters can be captured by your opponent, turning the tables and radically altering the course of the game.

The SmallRockets version of Backgammon has a host of features including multiple skill levels and game options, and should appeal equally to the Backgammon beginner as to the experienced player.
