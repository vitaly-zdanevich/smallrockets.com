Register for regular Rockets updates




  • Windows 95 / Windows 98 / Windows ME
  • IBM PC compatible processor - Intel Pentium II 233Mhz or equivalent AMD
  • 64MB RAM
  • Supported 3D Accelerator Card (8Mb minimum)
  • DirectX 7 or higher
  • 100MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • Kayak Extreme supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 2, Voodoo 3, Voodoo 5, Voodoo Banshee
    • 3D Labs Permedia 3
    • ATI Rage Pro Turbo (AGP only), Rage LT Pro, Rage 128, Rage 128 Pro, Rage MAXX, Radeon
    • Intel i740, i810
    • Matrox G400
    • Nvidia Riva TNT, TNT2 (all variations), GeForce, Quadro, GeForce2
    • S3 Savage 3D, Savage S4, Savage2000

    Comments

    • Kayak Extreme is not compatible with the following video chipsets - 3DFX Voodoo 1, 3DFX Voodoo Rush, 3DFX Velocity 100, 3D Labs Permedia 2, ATI Rage Pro Turbo PCI, Matrox G100, Nvidia Riva 128, Power VR PCX2, Power VR Neon 250, Rendition Verite v2x00, Rendition Verite V1000, SIS 6326.
    • Cyrix M2 - Unfortunately Cyrix M2 processors are not powerful enough to run the game. Only Intel and AMD processors are supported.
    • Users are advised to refrain from minimizing the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first.
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the 'Run' option on the START menu and typing 'DXDIAG') and select the 'Display' tab. This will list the device name and driver version.
    • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Kayak Extreme is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled 'Close Program'. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • Uninstalling - When the game is uninstalled, any 'ghost laps' that have been saved will be left behind on the hard drive. If you do not wish to keep these, they will need manually deleting from your system.
    • ATI Rage Pro and AMD K6 Systems - Users may experience some problems running Kayak when using the latest ATI release drivers (4.11.01.2560) with AMD K6 based systems. Should this be the case we suggest that users try the latest beta drivers available from ATI (version (4.11.01.2623) or (4.12.01.2632)). The drivers can be obtained from http://www.atitech.ca/na/pages/spdrivers/drivers.html Please note however that these drivers are unsupported by ATI at this time.
    • 3DFX Voodoo 2 and below spec cards - Kayak Extreme may fail to run on machines with a combination of a below spec Primary video card (which still has some 3D acceleration capabilities) and a 3DFX Voodoo 2 Secondary Adapter. If this occurs, reducing the Primary Adapters acceleration can solve it. This can be done by Right clicking on the Windows desktop and selecting 'Properties'. From the Display Properties menu that appears, select the 'Settings' tab then click on 'Advanced'. Next click on the 'Performance' tab of the menu that opens and change the Hardware acceleration slider from Full to Basic. Click OK to close the various windows and the machine will restart. Kayak Extreme should now run without any problems.
    • 3DFX Voodoo 2 - Problems may be encountered with the water effect within the game if played using the Secondary Adapter (Voodoo 2) on systems with certain high spec Primary Adapters (any Nvidia card, ATI Rage 128, 3D Labs Permedia 3, S3 Savage 4). This problem can be avoided by either playing the game using the 'Primary' Adapter (altered in the 'Video Options' menu), or by selecting the 'Secondary' Adapter in the Video Options menu and then restarting the game before playing a race (once this is done, the Voodoo 2 should function without any problems).
    • 3DFX Voodoo 3 - At high screen resolution and/or high detail settings, users may experience loss of some in-game textures. We recommend users set the display resolution to 640x480 and reduce detail settings if this occurs.
    • 3DFX Voodoo 5 - Users with Voodoo 5 video cards are advised not to have their desktop set to a resolution of 1280*1024*32-bit color or above, as doing so may cause the game to report the video card as insufficient and refuse to start. If the desktop resolution is reduced, Kayak Extreme will be able to run without any problems.
    • Nvidia TNT/TNT2/GeForce/GeForce 2 - Users with these video chipsets and the latest Nvidia Detonator drivers (Detonator 6.50) may find that a mouse cursor appears onscreen when a race is loaded. If this problem occurs, simply moving the mouse will remove the cursor from the screen.
    • Users with Microsoft Natural Keyboards - Using control setup 2 you may find that the shift key fails to function as normal. We advise users with these devices to use control setup 1.

    Sound Cards

    Kayak Extreme should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1
    • Aureal Vortex 2
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)
    • Crystal Sound Fusion (Videologic Sonic Fury)
    • Yamaha XG

    Comments

    • Users should ensure that they have DirectX 7 or above installed on their system. Earlier versions of DirectX (eg. DirectX 6.1) will run the game, but some sound effects may be missing.

Joysticks/Gamepads

Kayak Extreme can be controlled using a supported Windows compatible Gamepad with at least 6 buttons. The default game controls are

  • Direction left/right - Sharp turn left/right
  • Button 5 - Paddle Left
  • Button 6 - Paddle Right
  • Button 2 - Roll
  • Button 3 - Pirouette

    • USB Controllers - When using USB controllers (eg. Microsoft Sidewinder Gamepad Pro) we recommend that users install DirectX 7.0a or higher on their machine. This revision of DirectX includes better support for input devices, and without it USB controllers may fail to work with the game. Please see the DirectX section for more information and links to download sites.

    Kayak Extreme has been tested and found to work with the following products

    • Gravis - Xterminator, Xterminator Digital, Gamepad, Gamepad Pro
    • Interact - Makopad
    • Logitech - Wingman, Thunderpad Digital
    • Microsoft - Dual Strike, Sidewinder Gamepad, Sidewinder Gamepad Pro, Sidewinder Freestyle Pro
    • Saitek - P2000
    • Thrustmaster - Fusion

    Input Devices
    • Kayak Extreme only supports Gamepads with 6 buttons or more. Although Joystick controllers should function, they were not considered to provide a suitable control method and as a result are not supported.
    • With USB controllers DirectX 7a or above must be installed on the machine (more information and links to download the latest version can be found on the DirectX page).
