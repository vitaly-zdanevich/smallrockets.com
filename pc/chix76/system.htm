System Specification

The following are the system specifications (requirements) for Superchix '76:

  • Windows 95 / Windows 98
  • Intel Pentium II 233 or equivalent
  • 32Mb RAM
  • Supported 3D Accelerator Card (4Mb minimum)
  • 60MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • Superchix '76 supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 2, 3, Banshee and Velocity
    • 3D Labs Permedia 2 (AGP only) and Permedia 3
    • ATI Rage Pro Turbo AGP, Rage Pro Turbo PCI, Rage LT Pro, Rage128 and Rage Maxx
    • Intel i740
    • Intel 810
    • Matrox G200 and G400
    • Nvidia Riva 128, TNT, TNT2, Vanta, GeForce and Quadro
    • Rendition Verite V2x00 (8Mb minimum required)
    • S3 Savage 3D, Savage S4 and Savage2000
    • Videologic Neon 250

    Comments

    • The following 3D videocard chipsets are below the minimum required to run SuperChix’76 -Power VR PCX2, Matrox G100, Rendition Verite V1x00, SiS 6326, 3DFX Voodoo 1, 3DFX Voodoo Rush.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first.
    • Whilst SuperChix'76 takes up approximately 60Mb of hard drive space, more than this is required to actually run the game. Users are advised to keep at least 100Mb free for Windows to use as a swap file.
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
    • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Chix’76 is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • ATI Rage 128 and Super Socket 7 - If any problems are encountered when trying to run the game on a machine with a Super Socket 7 motherboard and an ATI Rage 128 video card, they can be solved by disabling the AGP support in DirectX. This can be done by running DXDIAG (use the RUN option on the Windows START menu and type ‘DXDIAG’). Once the DirectX Diagnostic Tool has opened, select the ‘Display’ tab and click on the icon next to ‘AGP Support’ to set it to Disable. N.B. We recommend that AGP support be enabled again once you finish playing (otherwise speed problems may be encountered with other software), this can be done by following the steps outlined above to disable AGP support and toggling the ‘AGP Support’ option to ‘Enabled’.
    • ATI Rage Pro and AMD K6 Systems - Users may experience some problems running Chix '76 when using the latest ATI release drivers (4.11.01.2560) with AMD K6 based systems. Should this be the case we suggest that users try the latest beta drivers available from ATI (version (4.11.01.2623) or (4.02.01.2632)). The drivers can be obtained from http://www.atitech.ca/na/pages/spdrivers/drivers.html please note however that these drivers are unsupported by ATI at this time.
    • Matrox Millennium G400 - Problems may be encountered with the Small Rockets logo flickering when the game is run using older drivers, this can be solved by installing the latest Matrox drivers (see below for details of the recommended drivers).
    • Neon 250 - Due to driver problems, the game will suffer from graphical corruption when run with Neon 250 video cards using the Driver Release v3.2.1.2 (Neon 250 - AGP 32Mb (11-3-1999) (4.11.01.10079)). To run the game we recommend using an older release of the cards drivers (see below for our recommended driver).
    • Nvidia Riva 128 - During testing, it was found that the best graphical results when using video cards with this chipset were obtained by using either the latest STB drivers for STB Velocity 128 cards or older drivers (v0127) for the Diamond Viper 330 cards (see below for details of the recommended drivers). Additionally, during play a flickering line may occasionally be seen along the base of the screen, this is due to limitations of the card.
    • 3dfx Velocity 100 - Due to hardware problems, the game will not work correctly in 1280x1024 screen resolution. The game works without any problems in all other screen resolutions however.

    Sound Cards

    Superchix '76 should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex (Terratec Xlerate)
    • Aureal Vortex 2
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • ESS ES1869
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)

    Comments

    • Videologic Sonic Storm - Due to driver problems, the game sound will not work correctly with default driver settings. To fix this problem you need to change the Hardware Sound Acceleration Level from 'Full acceleration' to 'Basic acceleration'. This can be done via DXDIAG, simply run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Sound’ tab. From this menu the 'Hardware Sound Acceleration Level' can be set.
    • Creative Labs Sound Blaster Live - If any problems are encountered with sections of the music looping during play, installing the latest drivers from Creative Labs should fix the problem.
    • The 'Voices' option is not selectable from the 'Options' menu until the Voice Patch add-on has been installed.

Steering Controls

 Superchix '76 has been tested and found to be compatible with a variety of steering devices (including USB peripherals).

Please Note - DirectX 7.0a or above may need to be installed on your system in order for USB devices to be recognised by the game. See the DirectX page for more details and links to download the latest version of DirectX.

The following steering devices have been tested successfully with Muscle Car 76

  • Microsoft Sidewinder Force Feedback Steering Wheel and Pedals
  • Thrustmaster Sprint Steering Wheel and Pedals
  • Thrustmaster Nascar Super Sport Steering Wheel and Pedals
  • SC&T Ultimate Per4mer Steering Wheel and Pedals
  • Interact V3 Racing Wheel & Pedals
  • Interact V4 Force Racing Wheel & Pedals
  • Interact FX Racing Wheelpad
  • Interact Ultraracer PC Wheelpad
  • CH Products EXL500 Racing Wheel & Pedals

Comments

  • The game supports no Force Feedback interaction, hence there is no particular benefit in using the Force Feedback function found on some of these devices.
