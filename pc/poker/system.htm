System Specification

The following are the system specifications (requirements) for Small Rockets Poker:

  • Windows 95 / Windows 98
  • IBM PC compatible processor, Pentium 166MMX or higher
  • 16Mb RAM (32Mb RAM recommended)
  • 10MB Free hard disk space
  • PCI/AGP Windows compatible video card (1Mb minimum)
  • Microsoft compatible Mouse

Comments

  • If any video problems are encountered, we recommend updating to the latest video drivers (see below for our list of recommended video drivers for the major video chipsets). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
  • If problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Small Rockets Poker is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
  • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
  • Windows Colour Mode - As the game runs in a window, the Windows colour mode setting can have an effect on the appearance of the game. Because of this we recommend that users do not run the game with a Windows desktop colour setting of 256 colours, as the graphical quality of the game may be downgraded. The optimum setting for appearance and speed is 16-bit colour.
  • 16 Colour mode (4 bit colour) - Poker does not work on anything lower than a 256 colour display.
  • Mouse Cursors - If any problems are encountered with customised Windows mouse cursors flickering during play, we recommend reverting to the default Windows cursors. The mouse cursor can be changed by opening the 'Control Panel' (found in the 'Settings' folder on the START menu) and double clicking on the 'Mouse' option. From the 'Mouse Properties' window that opens, select the 'Pointers' tab, then highlight the 'Normal Select' option and click on the 'Use Default' icon .
  • Under Windows 95, full screen mode works incorrectly at certain colour depths. Users should ensure their display is set to 16-bit colour mode, or run the game in windowed mode.
  • Rendition Verite v2200, S3 Trio 32/64 - Full Screen mode works incorrectly at certain colour depths. Users should ensure their display is set to 16-bit colour mode, or run the game in windowed mode.
  • Cirrus Logic Laguna - Poker doesn't run in 256-colour mode. Users are advised to set their display settings to High Colour (16 Bit) or higher.
