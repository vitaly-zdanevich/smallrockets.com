Linux Support

For our linux games to install and run correctly, please ensure you have libSDL 1.2 and GTK+ installed correctly.

For more information and installation files for these libraries, please visit www.libsdl.org and www.gtk.org respectively.

There's no sound

Are you sure you have:

  1. Set sound up correctly on your Linux installation. (eg under RedHat have you run sndconfig?)
  2. Speakers/head-phones connected to your machine/sound card.
  3. Turned the volume up on your speakers/headphones.
  4. Turned up the volume on your sound mixer

The game is slow/hard to control

This is probably because of how the game is configured and/or how your machine is set up. Therefore you need to reconfigure your machine and/or the game in order to increase performance. Please try the following ideas...

  1. Make sure you close down everything on your machine except for the game. The other programs will eat up some of your machine's resources. It is especially a good idea to close down mail/internet programs as they can interrupt the game, making gameplay 'jumpy' (stops and starts)

  2. If after trying the above you still find the game runs too slowly you might want to upgrade your machine. Here are some of the ways that will improve the performance of the game
  • Memory - More than 128Mb of memory (RAM) will likely make little difference though
  • Processor - Get a faster processor.
  • Video card - Buy a new card for your machine. If you have one of the cards listed in the support page for a game page it is probably fast enough.
These are the main features of your machine which will affect the performance of the game.

Why can't I play the full version?

Well, have you bought the full version of the game?

If no, then please go to the shop and purchase the game. For help on the shopping process go to the purchasing pages.

If yes, then the key is probably not installed correctly on your machine. To install a key

  1. Go to the install directory and run: ./setlicense
  2. Enter your username and license key for the game

The program will say if the key has been successfully installed.
