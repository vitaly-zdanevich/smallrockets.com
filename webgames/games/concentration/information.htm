Concentration

This is the classic memory game. To play, click on a tile to uncover an image - then choose another to try and match it.

If the tiles match, the tiles stay uncovered. Uncover all of them to win!

Click on 'reshuffle' to restart the game at any time.

About Concentration

This game utilizes JavaScript to work within web and set-top box browsers.

It is easily modifiable to use alternative tiles and has a minimal overhead ensuring a slick experience on any platform.
