Quiz

Test your general knowledge. Answer each question within ten seconds and see how many you can get right.

After you've answered 10 questions you'll find out how you did.

About Quiz

This game utilizes CGI scripts and JavaScript to work within web and set-top box browsers.

The game uses a database of questions which can be easily updated. The quiz can work with random question sets and can be configured to run competitions.

For more information on this game, please contact corporate@smallrockets.com.
